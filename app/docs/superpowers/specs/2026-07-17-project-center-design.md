# 项目中心双层结构设计规格

## 目标

将现有只能新建、复制、切换和导入导出的简单项目弹窗，升级为“快速项目弹窗 + 独立项目主页”的双层结构。用户既能在创作中快速切换项目，也能集中管理影调、运镜、角色、海报、反推和配乐六个工作台的项目状态。

## 分期与依赖

项目中心与音乐配乐是两个可独立验收的子项目，不在一次实施中同时改完。

1. 先实施并验收“音乐配乐”工作台，建立 `workspaces.music` 状态。
2. 再实施项目中心，一次性展示六个工作台，避免先做五项后再改数据和布局。

## 范围与边界

- 继续使用浏览器本地存储，不接入登录、云同步、订阅、计费或团队协作。
- 保持现有项目与工作台数据兼容，不要求用户重新建项目。
- 增加收藏、搜索、筛选、排序、重命名与六项状态摘要。
- 项目封面第一阶段使用本地生成的影片场记板式封面，由项目名、当前影调和状态色构成；不上传封面，不向 `localStorage` 写入 Base64 图片。
- 项目中心不修改六个工作台内部功能，只读取它们的项目摘要。

## 产品结构

### 第一层：快速项目弹窗

从顶部当前项目名打开，用于创作中的快速操作，不离开当前工作台。

- 顶部显示当前项目名、保存状态和关闭。
- 常驻操作为“新建项目”、“复制当前项目”和“查看全部项目”；弹窗顶部同时显示当前自动保存状态。
- 项目列表默认显示最近更新的 5 个项目，每项显示名称、更新时间、收藏状态和最后使用的工作台。
- 单击非当前项目直接切换，弹窗关闭并进入该项目最后使用的工作台。
- 弹窗中不放置删除、批量管理和大型导入导出操作，避免误触与信息过载。

### 第二层：独立项目主页

项目主页作为一个独立页面状态，不在六个创作工作台中再塞入一个第七栏。顶部仍保留产品标识和返回当前工作台的操作。

#### 顶部命令区

- 页面标题“项目中心”和本地保存边界说明。
- 项目搜索支持按名称实时筛选。
- 排序选项：最近更新、最近创建、名称 A–Z。
- 主操作为“新建项目”；导入、导出放入次级菜单。

#### 左侧导航

- 全部项目。
- 最近使用。
- 已收藏。
- 本地备份。
- 每个分类显示项目数量，选中状态同时使用文字和颜色表达。

#### 中央项目区

- 默认使用两列的横向影视项目卡片，优先展示项目内容和状态，不做大封面画廊。
- 每张卡片包含：自动封面、名称、创建时间、更新时间、最后使用的工作台、六项状态摘要和收藏按钮。
- 单击卡片选中项目并更新右侧详情；双击或“继续创作”打开该项目最后使用的工作台。
- 卡片更多菜单包含重命名、复制、导出和删除。
- 搜索无结果时显示清除筛选操作；本地没有项目时显示新建项目和导入备份操作。

#### 右侧项目详情

- 显示选中项目的完整名称、更新时间和“继续创作”主操作。
- 六个工作台依次显示影调、运镜、角色、海报、反推和配乐。
- 每项显示“未开始 / 已设置”、一行内容摘要和“打开”操作。
- 第一阶段不显示伪精确百分比。工作台是否“已设置”由独立摘要适配器判断，不使用对象大小或随意字段数量猜测。

## 工作台摘要规则

项目中心为每个工作台定义一个纯读摘要适配器，输出统一结构：

```js
{
  status: "empty" | "configured",
  title: "用户可读的核心选择",
  detail: "一行关键参数"
}
```

- 影调：已选风格、色调或光影中任意一项为已设置。
- 运镜：已选镜头案例或时间轴存在非默认调度为已设置。
- 角色：存在角色身份描述、参考素材或已保存版本中任意一项为已设置。
- 海报：存在海报用途、主体、标题或已选模板中任意一项为已设置。
- 反推：存在参考图文件名、非空八维校准或任务设置中任意一项为已设置。
- 配乐：已选模板，或用途、情绪、配器中任意一项为已设置。

摘要适配器只读取项目状态，不修改工作台数据。遇到损坏或未知版本数据时返回“无法读取”而不阻止项目列表显示。

## 数据模型与兼容

项目元数据增加：

```js
{
  favorite: false,
  lastOpenedAt: "ISO-8601 timestamp"
}
```

- `favorite` 缺失时默认为 `false`。
- `lastOpenedAt` 缺失时使用 `updatedAt`，再缺失时使用 `createdAt`。
- 新增字段不改变现有导出 JSON 的顶层结构。导入旧备份时补默认值；导入新备份时保留收藏和最后打开时间。
- 项目名去除首尾空白后必须为 1–60 个字符；允许重名，项目 ID 仍是唯一标识。
- 搜索不区分英文大小写，中文按子串匹配。
- 删除项目继续沿用现有角色素材保留与清理策略。

## 交互与错误处理

- 新建、复制和重命名成功后直接选中结果项目。
- 删除项目必须二次确认，明确显示项目名与本地数据后果；不允许删除唯一剩余项目。
- 导入前检查 JSON 结构；失败时不覆盖当前存储，并显示可理解的错误原因。
- 导出默认导出选中项目，“本地备份”中额外提供全部项目备份。
- 本地存储写入失败时保留当前内存状态，显示“未能保存到本地”，不显示虚假的“已保存”。
- 项目操作返回后保留当前搜索、分类、排序和选中状态，除非选中项目已被删除。

## 视觉方向

- 采用已确认的“影视项目台”方向：左侧筛选、中央项目卡片、右侧当前项目详情。
- 背景使用浅冷灰，内容面使用暖白，深灰文字，蓝绿作为主操作与状态强调。
- 封面和工作台状态承担页面的影像感，避免大面积纯黑、霓虹光晕、泛用渐变和巨大营销标题。
- 卡片圆角不超过 6px，不使用卡片内再嵌套卡片。
- 按钮、输入框、菜单和状态标识继续沿用全站现有操作语言。

## 响应式与无障碍

- 大于 1180px：左侧导航、中央项目区、右侧详情三栏。
- 820–1180px：收起左侧导航，中央项目区保留，右侧详情使用抽屉。
- 小于 820px：项目卡片单列，筛选进入菜单，详情使用全宽抽屉。
- 弹窗打开时焦点进入弹窗，`Escape` 关闭，关闭后焦点返回项目按钮。
- 卡片、菜单和抽屉均支持键盘操作，收藏、选中和保存状态不只依赖颜色。
- 所有宽度下不出现横向页面滚动、文字遮挡、操作被裁切或不可达。

## 验收标准

- 顶部项目按钮打开快速弹窗，可新建、复制当前项目、查看最近项目、快速切换和进入完整项目主页。
- 项目主页可按全部、最近和收藏筛选，可按名称搜索并按三种方式排序。
- 项目卡片与右侧详情均正确显示六个工作台的状态和摘要。
- 项目可新建、重命名、收藏、复制、切换、导入、导出和删除。
- 从项目主页打开某个工作台后，项目与工作台状态正确，返回项目中心后保留筛选与选中上下文。
- 导入损坏备份、写入本地存储失败和读取未知工作台状态时均有清楚反馈，不丢失现有项目。
- 现有项目导入导出、切换与角色素材清理测试继续通过。
- 1440、1280、1024 和 390 宽度无重叠、裁切和不可达操作。

## 非目标

- 不接入云端数据库、对象存储或第三方账号。
- 不设计付费套餐、权限墙或内容防拷贝方案。
- 不增加真实封面图上传、云端预览或跨设备同步。
- 不将项目中心变成营销首页，首屏直接提供项目管理和继续创作。
