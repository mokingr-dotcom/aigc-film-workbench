# 海报标题字设计库规格

日期：2026-07-19  
状态：待用户书面规格确认  
适用范围：海报生图工作台

## 1. 目标

在现有海报构图模板、影调、布光和文字设置基础上，增加一套可长期复用的电影标题字设计库。用户选择一个标题系统后，中间监视器立即显示对应的中英排版关系，右侧提示词同步得到字形、层级、字距、位置、材质和负面约束。

该功能服务于 AIGC 海报参考和提示词生成，不承担真实字体文件授权、矢量字标绘制或图像模型 API 调用。

## 2. 审核结论

现有 `poster-font` 只有九个泛化方向，无法表达中文与英文的配对关系、字距结构、材质和标题在画面中的叙事作用。简单增加更多下拉选项会降低可发现性，也无法让用户判断最终效果。

采用“中英成套标题系统”：每个模板同时规定中文主标题、英文伴随标题、层级比例和可选材质。模板名称描述设计原则，不使用受保护的电影 Logo 名称；参考影片只作为设计观察来源，不要求复刻专属字标。

## 3. 信息架构

左侧海报模板库增加二级页签：

- 构图模板：保留现有功能。
- 标题字模板：展示标题设计卡片。

标题字模板页包含：

- 类型筛选：全部、现代、历史东方、悬疑犯罪、科幻、文艺、喜剧动画。
- 语言模式：中文主标题、英文主标题、中英双语。
- 模板卡：样例标题、模板名称、适用类型、最多三部参考影片。

选择模板不改变海报构图、影调或主体，只更新标题设计状态。构图模板与标题字模板是两个独立选择，最终在提示词中组合。

## 5. 模板数据结构

新增 `poster-title-template-data.js`，每条数据至少包含：

- `id`：稳定存档标识。
- `label`：中文模板名。
- `category`：筛选分类。
- `languageModes`：支持的语言模式。
- `genreHints`：适用片种。
- `references`：两到三部带年份的参考影片。
- `cnRule`、`enRule`：中英字形和字距规则。
- `hierarchyRule`：主标题、副标题、英文伴随标题比例。
- `layoutRule`：横排、竖排、对齐和安全区规则。
- `materialOptions`：平面墨色、旧印刷、压印、石刻、暗金、发光等允许材质。
- `promptRule`：进入最终提示词的完整规则。
- `negativeRule`：该模板专属的禁止项。
- `previewClass`：本地 CSS 预览样式，不依赖远程字体。

## 6. 交互与监视器

1. 默认仍打开构图模板，避免改变老用户流程。
2. 切换到标题字模板时，左侧仅替换模板列表，不重置当前海报参数。
3. 点击整张标题卡即可选择；支持键盘焦点和 `aria-selected`。
4. 中间监视器显示用户真实主标题，而不是固定样例。
5. 中英双语模式下，英文伴随标题使用单独输入值；为空时显示安全占位，不伪造英文翻译。
6. 预览展示字重、宽窄、字距、大小关系、对齐和简化材质，不承诺浏览器字体与最终生成结果完全相同。
7. 文字生成方式继续支持：无字底图并保留排版区、直接生成标题、纯主视觉。
8. `visual-only` 模式下隐藏预览标题，但保留所选模板，切回文字模式后恢复。

## 7. 右侧参数

现有“文字与字体”折叠组调整为“标题字设计”，保留旧字段并新增：

- 标题语言模式。
- 英文标题或英文伴随标题。
- 标题材质。
- 模板摘要与参考影片。

原 `poster-font` 保留为兼容字段，由标题模板自动映射；用户仍可在“自定义”状态手动选择旧字体方向。旧项目没有 `titleTemplate` 时，根据原 `font` 映射到最接近模板，无法映射则使用默认“新宋体作者电影”。

## 8. 提示词输出

最终“字体与文字排版”段落按以下固定顺序生成：

1. 文字生成方式。
2. 准确的中文标题、英文标题、宣传语和附加层级。
3. 所选标题系统名称及中英字形规则。
4. 主副标题比例、字距、行距、对齐和安全区。
5. 标题材质、颜色以及与背景的反差方式。
6. 该模板专属负面限制。

不在提示词中要求“完全复制某电影字体”，不把三部参考影片同时作为生成风格指令。影片名称只显示在资料卡和模板说明中，最终生成提示词使用已经抽象后的设计规则。

## 9. 安全与版权边界

- 不打包、下载或声明使用任何未授权商业字体。
- 浏览器预览只使用系统字体栈和 CSS 变形模拟设计方向。
- 不提供电影 Logo 复刻，不使用“某某电影同款字体”作为生成命令。
- 用户标题和英文标题写入预览时使用安全文本节点或转义函数，禁止直接拼接未转义 HTML。
- 所有模板和筛选数据本地加载，不依赖网络。

## 10. 存档兼容

海报项目状态新增：

- `titleLibraryView`
- `titleCategory`
- `titleLanguage`
- `titleTemplate`
- `englishTitle`
- `titleMaterial`

导入时对每个值做白名单校验。旧项目继续读取 `font`、`titlePosition` 和 `textColor`，不丢失原设置。清空海报设置时恢复新默认值；示例按钮加载一组完整的中英标题示例。

## 11. 验收标准

- 16套模板全部可见、可筛选、可用整卡选择。
- 每套含中文规则、英文规则、材质、布局、负面词和2至3部参考影片。
- 选择模板后，监视器与提示词同步更新，不改变当前构图和影调。
- 三种语言模式与三种文字生成方式组合正确。
- 旧项目状态能够迁移，新增状态可保存、刷新恢复和导入导出。
- 用户输入 `<script>` 等内容只作为文字显示，不执行 HTML。
- 1440、1280、1024和390宽度无横向溢出、遮挡或不可达模板。
- 海报现有构图、用途、画幅、复制、示例、清空和跨工作台传递测试继续通过。
- 本地服务器页面无控制台错误，监视器标题在深色、浅色与复杂图片上保持可辨认。

## 12. 非目标

- 不接入字体下载、字体授权商城或文字转矢量服务。
- 不在本阶段增加图像生成 API、画布编辑器、自由拖拽文字或 PSD 导出。
- 不改造其他五个工作台。
