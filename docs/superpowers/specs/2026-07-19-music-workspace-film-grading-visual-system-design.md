# 音乐配乐工作台“胶片调色室”视觉系统设计

## 目标

将现有音乐配乐工作台从偏通用后台表单的视觉状态，升级为面向导演、摄影师、剪辑师和 AIGC 影视创作者的专业影视创作界面。设计必须适合长时间阅读和编辑，同时建立可用于未来订阅产品的品牌辨识度。

本阶段只改变“音乐配乐”工作台的视觉层级、排版与交互反馈，不改变案例数据、提示词逻辑、项目状态、模型适配器或三栏拖动功能。

## 唯一视觉基准

- 选定稿：`design-references/music-workspace-selected-film-grading-room.png`
- 目标视口：1440 x 1024。
- 视觉方向：胶片调色室与艺术电影工作手册的结合。
- 核心气质：温暖、克制、专业、具有电影行业辨识度，但不复古做旧。

实施和视觉验收只以该文件为基准。此前生成的其他方案、旧主题文件和临时覆盖样式均不作为视觉依据。

## 保留内容与行为

- 保留顶部工作模式导航及现有工作台切换。
- 保留左侧“影视配乐案例库”的搜索、用途、叙事类型、音乐语汇、案例选择和收藏。
- 保留中间“导演音乐设计”的画面叙事、风格情绪、配器组合、乐器浏览、节奏结构和高级控制。
- 保留右侧“配乐提示词输出”的目标模型、密度、导演分析、中英文提示词、排除项和复制功能。
- 保留三栏之间的拖动调整宽度。
- 保留现有 DOM ID、`data-workspace`、项目存取接口和键盘操作。
- 不新增音频生成、播放、上传、波形或 API 接入。

## 页面骨架

### 顶部导航

- 使用接近黑色的炭灰橄榄色，而不是纯黑。
- 高度保持紧凑，品牌、工作模式、搜索与项目操作在同一水平线上。
- 当前工作台使用一条细琥珀色下划线和更高文字对比表示，不使用大面积实色按钮。
- 不保留与任务无关的装饰性状态色图例。

### 三栏工作区

- 左栏为案例资料区，中栏为主要编辑区，右栏为输出区。
- 初始宽度比例固定为 `28% / 38% / 34%`；用户拖动后的比例继续按现有逻辑保存，视口不足时再受现有最小宽度约束。
- 三栏使用连续工作表面和细分隔线，不制作成三个悬浮大卡片。
- 每栏独立纵向滚动，栏标题与必要的顶部操作保持可见。
- 页面底部使用一条紧凑状态栏显示项目名、时长方式、速度和拍号；若某项没有真实数据则隐藏该项，不伪造信息。

## 视觉语言

### 颜色角色

- 页面画布：`#EEEDE8`，暖浅灰。
- 主工作表面：`#FBFAF6`，明亮暖白。
- 顶部导航与状态栏：`#20231F`，炭灰橄榄。
- 主交互色：`#4D6251`，深橄榄绿。
- 选中与时间线强调：`#B5813F`，低饱和琥珀色。
- 警告和错误：`#7A3F42`，克制酒红色。
- 轻选中表面：`#E7ECE6`，浅鼠尾草绿。
- 主文字：`#252622`。
- 次级文字：`#706F68`。
- 分隔线：使用主文字 12% 至 18% 透明度的等效颜色。

颜色必须按语义使用。橄榄绿只负责主操作和有效选中，琥珀色负责当前案例、节拍或工作进度，酒红色只负责风险提示。不得让三种强调色同时竞争主视觉。

### 字体

- 中文正文与控件使用清晰的系统无衬线字体栈，保证长时间阅读。
- 仅栏目主标题或少量英文标签可使用具有电影出版感的衬线字体；中文表单正文不得全面衬线化。
- 栏目标题建议 21 至 24px，分组标题 14 至 16px，正文和表单 14px，辅助信息不低于 12px。
- 字间距固定为 0，不使用负字距或随视口缩放的字号。

### 边框、圆角与阴影

- 主要控件圆角 4px，案例卡和输出块不超过 5px。
- 使用 1px 细边框和表面色差建立层级。
- 不使用大面积投影、玻璃模糊、霓虹描边或悬浮卡片墙。
- 卡片内部不再嵌套视觉卡片；信息通过排版、分隔线和小标题组织。

## 分区细节

### 案例库

- 案例卡采用配乐 cue sheet 结构：小幅 4:5 或 3:4 参考图、案例标题、时长/BPM、情绪、配器、节奏与制作信息。
- 参考图用于提高扫描效率，不得挤压正文；图片缺失时使用稳定的中性占位面，不改变卡片高度。
- 当前案例使用琥珀色细边和 `CUE 01` 等编号提示；未选案例保持中性边框。
- 整张案例卡可点击，收藏按钮保持独立操作。

### 导演音乐设计

- 中栏是页面视觉主角，使用最明亮的工作表面。
- “画面与叙事”“风格与情绪”“配器组合”“节奏与结构”使用编号、标题和细分隔线组织。
- 输入框保持足够高度，标签位于控件上方；同一行字段应等高。
- 配器组合使用紧凑矩形选择，不使用大量胶囊按钮。
- 乐器浏览器保持可组合逻辑，但通过地域、类型、声部的渐进层级降低一次性视觉噪声。

### 提示词输出

- 右栏像清晰的配乐记录与提示词转录区，不模拟终端或代码编辑器。
- 导演分析、Prompt、中文完整提示词、Exclude 使用一致的标题栏和文本表面。
- 复制操作位于每块右上角，并提供明确的短暂成功反馈。
- 错误提示使用浅酒红背景和左侧细线，不用高饱和整块红色。
- “纯音乐锁定”使用深橄榄按钮或状态控件，与主交互色一致。

## 动效与交互反馈

- 页面切换、筛选和展开采用 160 至 220ms 的淡入与位移，不做连续背景动画。
- 卡片悬停只改变边框、表面和轻微位移，禁止明显缩放。
- 拖动分栏时显示细高亮分隔线，松手后立即保存比例。
- 遵守 `prefers-reduced-motion`，关闭非必要过渡。
- 键盘焦点必须可见，使用主交互色外框并与鼠标悬停区分。

## 响应式规则

- 1440px：完整三栏，使用目标比例。
- 1280px：缩短顶部标签和内边距，保持三栏及可拖动分隔线。
- 1024px：三栏继续存在，但左栏与右栏使用各自最小宽度，中栏不得被压缩到无法编辑。
- 窄屏：改为工作区切换模式，一次显示案例、设计或输出中的一个；不将三栏强行缩成不可读的窄列。
- 所有断点不得出现水平溢出、文字遮挡、控件截断或固定宽度导致的空白。

## 实施边界

- 第一轮只实施音乐配乐工作台及其顶部活动状态。
- 不同时重做影调、运镜、角色定妆、海报和画面反推。
- 允许为音乐工作台建立独立视觉令牌和作用域样式，但不得继续追加无边界的全局覆盖。
- 现有全局 CSS 冲突只处理确实影响音乐工作台的规则；其余工作台保持现状。
- 用户确认音乐工作台后，再制定其他工作台迁移到同一视觉系统的计划。

## 验收标准

- 真实页面在 1440 x 1024 下与选定视觉稿并排比较，三栏比例、色彩角色、标题层级和主要表面关系一致。
- 页面不再呈现纯黑压顶、灰色边框等权或青绿与金色互相竞争的问题。
- 关键中文文字清晰，正文不低于 14px，辅助信息不低于 12px。
- 案例卡整卡可点击；筛选、乐器组合、模型切换、复制和三栏拖动行为保持可用。
- 1440、1280、1024 和 390px 视口无水平溢出、遮挡或不可读区域。
- 浏览器控制台无新增错误；现有提示词与项目状态测试全部通过。
- 单元测试通过不能替代视觉验收；视觉不一致必须先修正再交付。
