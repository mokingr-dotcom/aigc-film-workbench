# AIGC 影视项目引导与视觉圣经设计规格

## 决策摘要

本阶段把产品从“六个独立提示词工作台”升级为“可交付的 AIGC 影视前期制作流程”。首批核心用户是独立创作者、小型影视与广告团队、剧情短视频创作者；商品图、自媒体封面和品牌视觉保留为后续的“商业视觉”产品线，不进入本轮实施。

用户确认以下方向：

- 影视 / AIGC 短片为第一条完整制作流程。
- 新用户默认从故事或创意简报开始；已有参考图是第一步可选入口。
- 新建项目后进入一次性的“导演启动台”。
- 启动台采用项目简报、视觉方向、创作路线三步结构。
- 产品同时提供引导模式与专业模式；专业模式保留现有六个工作台的自由入口。
- 项目视觉圣经是各工作台的共享基准，支持草案、锁定、局部覆盖与更新项目基准。

本规格在不推倒现有项目中心、六个工作台、提示词资产和本地优先存储的前提下，扩展项目建立与项目内导航体验。

## 产品目标

1. 新用户在 30 秒内理解从哪里开始制作一部 AIGC 影片。
2. 用户在 5 分钟内建立可被角色、运镜、海报与配乐复用的项目视觉基准。
3. 用户无需在每个工作台重复填写年代、画幅、影调、人物与约束。
4. 熟练用户可跳过引导，不受线性步骤限制。
5. 项目完成后可逐步汇总为模型适配的制作资料包；本阶段先建立资料结构与入口，不实现完整导出中心。

## 范围与分期

### 本阶段：项目基础闭环

- 导演启动台：项目简报、视觉方向、创作路线。
- 项目视觉圣经：草案、锁定、项目级基准与局部覆盖。
- 项目桌面：显示视觉圣经摘要、阶段状态、继续当前制作和专业模式入口。
- 工作台继承：首先以可见的继承摘要和可复制文本为主；不重写每个工作台的表单逻辑。
- 本地项目数据迁移、导入导出兼容与回归测试。

### 下一阶段：影视制作交付

- 项目镜头清单与连续性记录。
- 角色、镜头、海报、配乐的交付中心。
- Seedance、即梦、可灵、Runway、Suno 等模型的导出适配器。

### 后续产品线：商业视觉

- 商品主体与品牌视觉锁定。
- 商品白底图、场景图、详情页图、广告素材与多比例输出。
- 自媒体封面和商业海报流程。

## 用户路径

```text
项目桌面
  -> 新建影视项目
  -> 导演启动台
       1. 项目简报
       2. 视觉方向与参考图
       3. 创作路线
  -> 项目桌面（引导模式）
       -> 视觉圣经
       -> 推荐的下一工作台
  -> 专业模式
       -> 影调 / 角色 / 运镜 / 海报 / 反推 / 配乐
```

### 引导模式

引导模式服务第一次使用本产品的创作者。它只负责给出合理顺序和项目上下文，绝不锁死工作台。

- 新项目默认打开启动台，而不是直接打开空白影调库。
- 启动台完成后回到项目桌面，主操作为“继续当前制作”。
- 项目桌面按视觉方向、角色与参考资产、镜头与运镜、宣传视觉、配乐、交付资料显示阶段状态。
- 用户始终能选择任一阶段或点击“专业模式”。

### 专业模式

- 顶部现有七个入口保持：项目、影调、15 秒运镜、角色定妆、海报、画面反推、音乐配乐。
- 专业模式不显示强制步骤弹窗。
- 每个工作台显示项目继承信息，并允许当前内容局部覆盖。
- 切换回项目桌面时保留项目筛选、当前项目和最后编辑工作台。

## 导演启动台

启动台是项目创建后的全屏但非沉重流程，进度固定为 3 步，支持返回、暂存与“跳过引导”。每一步内容应控制在一屏内完成。

### 第一步：项目简报

必填字段：

- 项目名称。
- 制作类型：剧情短片、剧情短视频、广告 / 宣传片、纪录片、动画、剧集。
- 一句话故事或创意任务。
- 主要发布平台：横屏影片、竖屏短视频、社交媒体、提案 / Pitch。
- 画幅与预计时长。

可选字段：

- 年代、地域、目标生成模型。
- 已有角色图、场景图、海报或电影截图。上传只进入本地项目资产引用，不写入 JSON Base64。

### 第二步：视觉方向

用户无需在此直接浏览完整资料库。系统提供三组可组合选择：

- 影片气质：写实、诗意、悬疑、商业、史诗、纪实、未来、温暖生活等。
- 影调方向：从已有影调资料库提取的少量精选方向。
- 参考来源：导演 / 影片 / 用户上传参考图。

用户确认后生成视觉圣经草案。用户可直接确认、进入影调库细调，或稍后处理；任何默认预览都不得被计为已完成项目设定。

### 第三步：创作路线

用户选择“现在最先做什么”：

- 先定角色。
- 先做镜头。
- 先出海报。
- 先做配乐。
- 先浏览资料。

选择只影响项目桌面的下一步建议与启动后跳转，不阻止其他工作台访问。

## 项目视觉圣经

### 数据模型

在 `project` 顶层新增 `creativeBrief` 和 `visualBible`。工作台已有的 `workspaces` 数据保持原结构，不创建平行项目库。

```js
{
  creativeBrief: {
    story: "一句话故事或商业任务",
    platform: "film | short-video | social | pitch",
    era: "当代 / 1990 年代 / 自定义",
    region: "地域或文化语境",
    targetModels: ["seedance"],
    route: "casting | camera | poster | music | library",
    referenceAssetIds: []
  },
  visualBible: {
    status: "draft | locked",
    toneItems: [{ category: "directors", id: "D004" }],
    mood: "克制悬疑",
    palette: ["#..."],
    colorDirection: "冷灰与低饱和暖点",
    lightingDirection: "侧逆光，暗部保留细节",
    cameraDirection: "宽银幕、缓慢推轨、自然景深",
    materialDirection: "真实皮肤、湿玻璃、低颗粒胶片",
    negativeConstraints: ["避免塑料皮肤"],
    updatedAt: "ISO-8601 timestamp"
  }
}
```

迁移规则：旧项目缺少字段时补空对象和 `visualBible.status = "draft"`，不从默认工作台状态猜测用户意图。已有影调工作台中标记为用户主动选择的项目，可在首次打开视觉圣经时作为“建议导入”，不自动锁定。

### 草案与锁定

- 草案允许持续从影调库、参考图或手动编辑变化。
- 锁定表示该项目有一个明确视觉基准，不表示工作台不可编辑。
- 工作台局部覆盖只写入自身状态，不能静默修改视觉圣经。
- 用户可显式执行“更新项目基准”，系统应显示受影响字段和确认提示。
- 解锁后仍保留上一次锁定内容，方便比较和恢复。

### 工作台继承

所有工作台新增统一的“项目视觉基准”区域，显示：项目名、画幅、年代 / 地域、视觉圣经状态、已继承影调摘要、角色或参考素材摘要、目标模型。

每个工作台可选择：

1. 使用项目基准。
2. 仅覆盖当前内容。
3. 将当前内容中的选定字段更新为项目基准。

本阶段优先实现“可见继承摘要 + 写入提示词”的兼容层。对每个已有工作台的深层字段映射将在实施计划中单独列出并逐项验证，避免一次性改动造成既有提示词回归。

## 项目桌面升级

项目桌面保留既有三栏结构，但首屏优先级改为：

1. 当前项目与一句话故事。
2. 视觉圣经状态和四项摘要：影调、光影、摄影、材质。
3. 六阶段制作进度与推荐下一步。
4. 最近编辑的工作台与继续创作操作。

“继续当前制作”遵循以下规则：

1. 视觉圣经未锁定时，打开视觉圣经。
2. 已选择启动路线且对应工作台未完成时，打开该工作台。
3. 否则打开项目 `activeWorkspace`。
4. 无历史工作台时，提示影调生成。

顶部“专业模式”是明确的模式入口，不增加新的项目 `workspace` ID；项目桌面仍不能写入 `activeWorkspace`。

## 交付中心预留

本阶段项目桌面显示“制作资料”入口和各类别状态，但不承诺完整导出功能。数据模型必须为后续导出保留稳定来源：项目简报、视觉圣经、工作台状态和资产引用。

未来交付包包括：视觉圣经、角色设定、镜头提示词、海报方案、配乐提示词、统一负面约束和目标模型版本。

## 错误、隐私与存储

- 继续沿用本地优先存储；不接入账号、云同步、订阅或生成模型 API。
- 参考图和角色图仅保存本地资产元数据及 Blob，不将图片 Base64 写入项目 JSON。
- 资产缺失时显示可恢复的“参考素材不可用”，不清空视觉圣经文本。
- 视觉圣经解析失败时显示草案状态与修复入口，其他工作台继续可用。
- 导入旧项目时字段非法必须回退空值，不阻断整个项目库。

## 验收标准

### 行为

- 新用户可在 30 秒内从项目简报进入视觉圣经草案。
- 任何默认预览、默认影调、默认运镜、默认海报或默认音乐不得增加项目完成数量。
- 锁定视觉圣经后，六个工作台均能读取同一份继承摘要。
- 当前工作台局部覆盖不会改写项目视觉圣经；用户明确确认后才可更新项目基准。
- 跳过引导后用户直接进入专业模式，现有六个工作台功能保持可用。
- 旧项目、本地导入导出、跨工作台传递、角色与海报本地资产继续可用。

### 视觉与可访问性

- 导演启动台在 1440、1280、1024、820、390 宽度下无文字遮挡或横向溢出。
- 三步进度、跳过、返回、保存草案与当前步骤具有清晰文本状态，不能只依赖颜色。
- 不以大型营销 Hero 替代项目工具；维持克制、专业、电影感的工作台审美。
- 视觉圣经摘要可快速扫描，不以长段提示词作为主要界面内容。

### 非目标

- 不在本阶段接入图片、视频或音乐生成 API。
- 不构建聊天式 Agent。
- 不重写六个工作台内部布局。
- 不在本阶段实现完整项目导出、镜头清单或商品图工作台。
- 不建立公开营销首页、订阅支付、账号和团队协作。
