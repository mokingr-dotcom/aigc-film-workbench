# AIGC 电影提示词工作台 (AIGC Film Workbench)

这是一个面向专业导演和 AIGC 创作者的影视生产管线工具，旨在通过“视觉圣经”和“资产锁定”技术，解决 AIGC 电影创作中的连续性与专业性痛点。

## 🎬 核心功能模块 (导演级增强)

本项目在基础版上进行了深度架构升级，后续维护请重点关注以下模块：

### 1. 视觉圣经贯穿 (Visual Bible Integration)
- **核心文件**：`project-context.js`
- **逻辑**：通过 `Auto-Prompt` 接口实现全站影调同步。一旦在项目中心锁定视觉基准，影调、材质、光影参数会自动注入到镜头、海报和角色定妆的提示词中。

### 2. 项目总监视墙 (Production Monitor Wall)
- **核心文件**：`project-scenes.js`
- **入口**：项目桌面 `05 审片` 阶段。
- **功能**：汇总全片已生成的视频/图片资产，支持“全片连播序列”校验。点击卡片可一键跳转回对应场次进行微调。

### 3. 角色表演预设 (Performance Presets)
- **核心文件**：`casting-app.js`
- **功能**：在角色定妆模块提供“克制愤怒”、“隐忍悲伤”等导演级预设。一键填充专业微表情与身体状态描述，并支持同步至项目资产库（CHAR-XXX）。

### 4. 智能剧本分析 (Smart Script Analysis)
- **核心文件**：`project-store.js`
- **功能**：增强了本地关键词识别。系统会自动根据剧本动作（如“穿过”、“紧攥”）建议景别（特写/全景）和运镜（跟随/缓推）。

### 5. 全局指挥中心 (Command Center)
- **快捷键**：`⌘ + K` (Mac) / `Ctrl + K` (Win)
- **核心文件**：`look-studio.js`
- **功能**：支持全站搜索项目、场次、运镜案例、配乐风格及海报模板。

## 🛠 维护与开发指南

### 1. 代码同步
每次开发前，请务必执行：
```bash
git pull origin main
```

### 2. 回归测试
修改核心逻辑后，请运行测试脚本确保没有破坏原有的提示词生成合同：
```bash
node prompt-generator.test.js
```

### 3. 部署
本项目已关联 Vercel 自动部署，任何推送到 `main` 分支的代码都会自动生效。
