# 15 秒运镜均衡制作台排版设计

## 目标

调整“15 秒运镜”工作台的三栏比例和文字层级。中间监视器不再占据主要视野，两侧运镜资料和提示词字段获得更稳定的阅读宽度与字号，同时保留现有运镜案例、时间轴、版本、提示词生成和跨工作台数据。

## 当前问题

- 桌面端实际三栏约为 `270px / 655px / 360px`，视觉重心过度集中在监视器。
- 监视器在常用桌面高度下约 `535px` 高，压缩了时间轴信息。
- 左侧案例标题约 `11px`、说明约 `9px`；右侧标签约 `9px`、输入文字约 `10px`，长期阅读负担较大。
- 1024px 以下虽然改为上下排列，但监视器仍会因中间弹性行而变得过高。

## 选定方向

采用“均衡制作台”布局，不增加折叠侧栏和新的交互模式。

### 桌面端

- 大于 1280px：左侧运镜库约 `300px`，右侧提示词区约 `420px`，中间区域使用剩余宽度，目标约 `520–580px`。
- 1025–1280px：左侧约 `280px`，右侧约 `390px`，中间保持至少约 `460px` 的可用宽度。
- 中间监视器保持宽银幕完整构图，视觉高度控制在约 `340–380px`；释放出的垂直空间分配给 0–15 秒时间轴。
- 不裁切监视器图片，不改变当前案例图片、时间轴数据或保存版本逻辑。

### 文字层级

- 左侧案例标题提高到 `12px`，分类与说明提高到 `10px`。
- 搜索框、筛选器和分段控制文字不低于 `11px`。
- 右侧字段标签提高到 `11px`，输入框与普通文本提高到 `12px`。
- 完整提示词正文提高到 `12px`，行高保持约 `1.6`。
- 中间时间轴标题、轨道标签和内容同步提高一级，但避免挤压轨道结构。

### 窄屏与手机

- 1024px 以下继续使用“监视器、运镜库、提示词”纵向顺序，不改变现有工作流。
- 监视器使用稳定的 `16:9` 比例，不再由剩余视口高度无限拉伸。
- 560px 以下保持单列按钮与字段布局，文字不得使用视口缩放字号。

## 约束

- 只修改运镜工作台相关 CSS 和必要的布局回归测试。
- 保留现有 HTML IDs、`camera-*` 数据结构、版本保存、案例筛选、提示词复制与工作台传递。
- 不重构影调、角色定妆、海报和画面反推页面。
- 不引入新的依赖、网络资源或折叠交互。

## 验收标准

- 1440 和 1280 宽度下，中间监视器明显小于当前版本，两侧信息宽度增加。
- 左右两侧主要文字达到上述字号，不出现截断、重叠或按钮溢出。
- 监视器画面保持完整宽银幕构图，时间轴获得更多可见空间。
- 1024、600 和 390 宽度下采用稳定上下排列，监视器保持 16:9。
- 运镜案例选择、搜索筛选、时间轴、版本保存、提示词生成和复制行为保持正常。
- 现有回归测试通过，并增加三栏比例、监视器尺寸和文字层级的防回退检查。
