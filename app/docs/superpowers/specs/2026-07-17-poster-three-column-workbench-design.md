# 海报三栏制作台设计规格

## 目标

将现有海报页从“左侧长表单 + 右侧长提示词”改造为导演、摄影师和 AIGC 创作者可以长期使用的三栏海报制作台。核心流程是：选择用途与视觉模板，在中央检查构图和排版区，在右侧完成参数并复制独立提示词。

## 范围

- 只重做 `#poster-workspace`，不改影调、15 秒运镜、角色定妆和画面反推工作台。
- 保留现有海报业务数据、提示词组合逻辑、项目保存、影调与角色传递、复制、清空和载入示例。
- 保留所有已有表单 ID 与 `aigcPosterWorkbench` 对外接口。
- 本阶段不接入生图 API，产品仍是海报视觉参考和提示词制作工具。

## 视觉方向

- 沿用已确定的冷灰绿、暖白和深色顶部命令栏，与运镜和角色工作台保持一致。
- 信息密度为均衡偏高，不使用大面积纯黑、霓虹渐变、玻璃卡片或科幻控制台装饰。
- 卡片圆角不超过 5px，边界主要通过细边线、色阶和间距建立。
- 模板库和中央预览使用本地位图视觉样片，不使用占位框、CSS 人像形状或文字代替真实画面。

## 桌面布局

1440px 宽度下采用三栏：

1. **左栏：海报模板库，默认 320px**
   - 顶部为用途切换：电影海报、自媒体封面、商品主视觉。
   - 下方为可滚动的视觉模板卡片，显示真实缩略图、模板名、适用类型和构图摘要。
   - 电影海报默认显示人物大脸、小人物与宏大环境、双人对峙、群像金字塔、双重曝光、关键物件、斜线动作、文艺留白和双世界。
   - 自媒体和商品切换后只显示对应模板，不混入电影构图。

2. **中栏：海报视觉监看，自适应宽度，最低 420px**
   - 顶部显示当前模板、用途和比例。
   - 支持 `2:3`、`4:5`、`9:16`、`16:9`、`3:2`和 `1:1` 比例切换。
   - 中央画布显示与当前模板对应的位图样板、主体占比、文字安全区和标题位置。
   - 画布下方显示当前构图的“视觉意图、主体占比、排版风险”，帮助用户理解选择。
   - 不提供真实生图画布和节点编辑。

3. **右栏：海报参数与提示词，默认 500px**
   - 顶部保留有参考图 / 纯文字新建模式。
   - 参数按“主体、场景、影调与光影、字体排版”四组组织，默认展开当前工作组，其余组保持可扫描标题。
   - 底部固定验证状态、完整提示词和复制操作。
   - 提示词区文字不小于 12px，行高不小于 1.6。

两条栏间分隔线支持鼠标拖动、键盘方向键微调和双击复位；宽度保存到当前项目。

## 交互与数据流

- 切换用途时，自动替换比例、可用模板和默认视觉重点，但不清空用户已填写的主体与文字。
- 选择模板后，左栏高亮、中央样板、构图说明和右侧提示词同步更新。
- 影调、光影和色彩均为单选逻辑，新选择替换旧选择，不自动叠加多套风格。
- “有参考图”模式在提示词中锁定人物或商品；“纯文字新建”禁止使用参考图规则。
- 文字模式保留“无字底图、直接生成文字、纯主视觉”三种。
- 验证继续检查主体、环境、光源、影调、标题和参考模式。
- 所有修改通过现有 `aigcPosterWorkbench.exportState()` 进入项目保存。

## 提示词规则

- 保留已有生成任务、主体模式、构图、项目影调、类型影调、电影布光、色彩关系、字体排版、完成度和限定负面词结构。
- 每个模板只输出它自己的构图规则，不同时引用多个海报案例。
- “电影海报”输出真人电影或所选动画类型的 Key Art 规则；“自媒体封面”强化缩略图识别和标题区；“商品主视觉”强化产品外形、材质、品牌区和接触阴影。
- 参考影片只作为单个模板的视觉说明，不把多部电影名同时写入最终提示词。

## 响应式

- `1180px` 以上显示三栏和拖杆。
- `820px–1180px` 改为“中央预览 → 模板库 → 参数提示词”上下顺序，隐藏拖杆。
- `820px` 以下为单栏，模板卡改成横向滚动，表单组单列排列，提示词保持可编辑。

## 无障碍与状态

- 用途、模式和比例控件使用正确的 `aria-pressed` 或原生表单状态。
- 模板卡支持键盘聚焦和 Enter / Space 选择。
- 拖杆使用 `role="separator"`，提供当前值、最小值、最大值与方向键操作。
- 复制按钮在缺少必填信息时禁用，验证结果同时通过颜色和文字呈现。
- 聚焦轮廓、按钮文字、输入框标签和辅助文字达到 WCAG AA 对比度。

## 验收标准

- 1440×1024 首屏中三栏完整，无左右裁切，中央样板是第一视觉焦点。
- 切换电影海报、自媒体封面和商品主视觉时，模板、比例、中央样板和提示词同步变化。
- 无参考图模式、有参考图模式、三种文字模式和全部比例可用。
- 左右栏可拖动、键盘调整、双击复位，刷新后宽度恢复。
- 所有现有海报字段 ID、项目导入导出和跨工作台传递通过回归测试。
- 1440、1280、1024 和 390 宽度无重叠、溢出或不可达内容。
- 浏览器控制台无错误和警告。

## 非目标

- 不接入任何第三方生图模型。
- 不新增登录、付费、云端存储或订阅逻辑。
- 不改动整站顶部导航和其他工作台视觉。
