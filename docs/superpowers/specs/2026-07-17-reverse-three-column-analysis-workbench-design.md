# 画面反推三栏分析台设计规格

## 目标

将现有“左侧长表单 + 右侧长指令”的画面反推页面重构为适合导演、摄影师和 AIGC 创作者持续使用的三栏分析台。用户可以上传参考图进行本地监看，逐项校准八个视觉维度，并得到一份包含复刻提示词、限定负面词和技术参数摘要的完整中文反推指令。

## 范围

- 只重构 `#reverse-workspace`，不修改影调、15 秒运镜、角色定妆和海报工作台。
- 保留现有反推用途、复刻强度、重点加强、目标比例、完成度、文字处理、主体替换和补充要求。
- 保留本地图片选择、载入示例、清空、复制、项目保存和项目恢复。
- 保留现有字段 ID 与 `window.aigcReverseWorkbench` 对外接口。
- 新增八个可编辑分析字段和两条可调整栏宽的分隔线。
- 本阶段不接入识图 API，不自动分析图片，不增加云端图片存储。

## 产品原则

- 网站明确区分“本地参考图预览”和“目标看图模型分析”：本网站只展示图片并组织指令，不声称已经识别图片内容。
- 八维字段允许用户人工填写、粘贴外部分析结果或保持空白。
- 已填写内容属于人工确认约束，在最终指令中优先级高于目标模型的推测。
- 空白维度继续由目标看图模型按照固定分析标准补全。
- 参考图只在当前浏览器会话中预览；项目保存图片文件名和八维文字，不保存图片 Blob 或 Base64。

## 桌面布局

1440px 宽度采用三栏结构。

### 左栏：参考图与任务，默认 300px

- 顶部显示 `REFERENCE INPUT`、当前图片状态和隐私边界。
- 参考图使用 16:9 监看区域，图片采用 `object-fit: contain`，不得裁切、拉伸或遮挡。
- 支持“目标 AI 中上传参考图”和“本地选择图片做项目记录”两种现有模式。
- 本地模式支持选择、替换和清除当前参考图；图片只生成当前会话 Object URL。
- 图片下方集中显示：
  - 反推用途
  - 复刻强度
  - 重点加强
  - 目标画面比例
  - 画面完成度
  - 文字处理
  - 主体替换要求
  - 补充要求
- 左栏拥有独立滚动区域，字段标签和说明文字不得被图片覆盖。

### 中栏：八维可编辑拆解，自适应宽度，最低 500px

- 顶部显示 `VISUAL BREAKDOWN` 和 `已校准 N/8`。
- 八个维度依次为：
  1. 主体特征
  2. 构图方式
  3. 镜头角度
  4. 光线方向
  5. 色彩搭配
  6. 材质细节
  7. 画面风格
  8. 背景元素
- 每个维度使用一个可编辑文本区，字段内引导用户同时填写“观察到的证据”和“可执行生成参数”。
- 每个维度显示简短分析标准，但不把长篇固定说明全部常驻在首屏。
- 字段允许为空，不因空白阻止复制；空白状态显示“由目标模型补充”。
- 非空字段显示“人工校准”状态，并计入 `N/8`。
- 提供“清空八维校准”命令，但不清除左栏任务设置。
- 八维区域独立滚动，桌面端采用两列四行或密度相当的布局，保证文本区具有可编辑高度。

### 右栏：反推输出，默认 500px

- 顶部显示 `ANALYZE → REBUILD` 状态、载入示例、清空和复制。
- 显示参考图状态、八维校准进度和当前输出用途。
- 输出区保持一个完整可复制指令，不拆成互相冲突的多个提示词版本。
- 完整指令固定包含：
  1. 任务与看图要求
  2. 八维分析标准
  3. 人工确认约束
  4. 复刻边界与主体替换
  5. 画幅、完成度与文字策略
  6. 输出格式
  7. 限定负面词要求
  8. 技术参数摘要要求
- 提示词文本不小于 12px，行高不小于 1.6。
- 底部保留建议文件名和项目记录状态。

## 栏宽调整

- 左栏与中栏、中栏与右栏之间各有一条分隔线。
- 鼠标拖动实时调整栏宽。
- 分隔线支持键盘方向键微调，`Shift + 方向键` 加速调整。
- 双击分隔线恢复默认值：左栏 300px、右栏 500px。
- 中栏始终保持至少 500px；左栏限制为 270–420px，右栏限制为 420–620px。
- 栏宽保存在当前反推工作台项目状态中，旧项目缺少布局数据时使用默认值。

## 八维数据模型

在现有反推状态中新增：

```js
dimensions: {
  subject: "",
  composition: "",
  camera: "",
  lighting: "",
  color: "",
  material: "",
  style: "",
  background: ""
},
layout: {
  leftWidth: 300,
  rightWidth: 500
}
```

- 每个维度保存纯文本，不保存富文本或 HTML。
- 导出和导入时忽略未知维度，并为缺失维度补空字符串。
- 八维进度只统计去除首尾空白后仍有内容的字段。
- 项目恢复时显示图片文件名，但本地图片预览为空，并明确提示重新选择图片。

## 提示词合成规则

- 固定分析标准继续来自现有 `dimensionRules`，确保空白维度仍有完整分析要求。
- 新增“人工确认约束”段落，只列出非空维度。
- 人工确认段落格式统一为：`维度名称：用户填写内容`。
- 指令明确要求目标模型：
  - 不得覆盖人工确认内容。
  - 对空白维度根据参考图补充。
  - 无法确认的内容写“无法确认”，不得编造。
- 最终生成提示词仍不得引用导演、艺术家、影片、相机和镜头型号作为未经证实的事实。
- 复刻边界继续禁止复制明星脸、受保护角色、品牌标识、Logo、版权文字和水印。
- “限定负面词”根据用途、人工校准与现有通用约束生成，不同时叠加互相冲突的画面风格。

## 验证与错误状态

- “目标 AI 上传参考图”模式允许直接复制，提示用户在目标模型中同时上传图片。
- “本地选择图片”模式未选择图片时禁用复制，并显示明确错误。
- 文件类型继续限制为 JPEG、PNG 和 WebP。
- 如果文件无法预览，保留原任务设置和八维文字，并显示替换图片操作。
- 清空全部内容前不增加确认弹窗，沿用现有即时清空行为；“清空八维校准”只清八维字段。
- 复制成功后按钮短暂显示“已复制”，失败时继续使用现有选区复制回退逻辑。

## 视觉方向

- 沿用已确认的海报工作台冷灰绿、暖白、深色顶部命令栏和细边线体系。
- 避免大面积纯黑、霓虹渐变、发光控制台和装饰性玻璃卡片。
- 卡片圆角不超过 5px；八维区域主要使用分隔线、编号和状态色建立层级。
- 中栏是主要工作区，参考图是第一视觉锚点，右栏提示词保持可读但不压缩中栏。
- 颜色状态不能作为唯一反馈，必须同时显示“人工校准”“由目标模型补充”等文字。

## 响应式

- 大于 1180px：三栏布局与可拖动分隔线。
- 820–1180px：按“参考图与任务 → 八维分析 → 输出”纵向排列，隐藏分隔线。
- 小于 820px：单栏；八维字段改为一列；任务设置改为单列；工具栏按钮不得换成不可识别的纯图标。
- 所有宽度下不得出现横向页面滚动、文字遮挡、参考图裁切或不可达输入框。

## 无障碍

- 八维字段均有可见标签和与其关联的输入控件。
- 校准状态通过文字与颜色同时表达。
- 分隔线使用 `role="separator"`、`aria-orientation="vertical"`、当前值和最小/最大值。
- 所有按钮、输入框、分隔线均有清楚的键盘焦点状态。
- 文本、占位符、辅助说明和错误信息达到 WCAG AA 对比度目标。

## 验收标准

- 1440×1024 首屏三栏完整，左、中、右信息均可阅读，中栏不小于 500px。
- 本地图片完整显示，切换图片模式不会丢失任务设置和八维文字。
- 八个维度可以独立编辑、清空、保存、导入和恢复。
- `已校准 N/8` 与实际非空字段数量一致。
- 非空维度进入“人工确认约束”，空白维度仍由固定规则要求目标模型分析。
- 复制、清空、载入示例、文件名和项目保存继续工作。
- 两条分隔线支持拖动、键盘、双击复位和项目恢复。
- 1440、1280、1024 和 390 宽度无重叠、裁切或横向溢出。
- 浏览器控制台无错误和警告。
- 现有自动测试与新增反推测试全部通过。

## 非目标

- 不接入任何多模态识图模型或第三方生成 API。
- 不把本地参考图写入项目 JSON、localStorage、IndexedDB 或云端。
- 不新增登录、付费、订阅和内容保护功能。
- 不新增跨工作台发送功能；待五个工作台视觉统一后单独设计数据传递规则。
- 不重构全站顶部导航、项目中心或其他工作台。
