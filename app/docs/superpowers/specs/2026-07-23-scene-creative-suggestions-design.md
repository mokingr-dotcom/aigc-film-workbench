# 场次影调与运镜建议设计

## 目标

把剧本分析草稿中的静态“导演建议”升级为可选择、可应用的场次视觉方案，使用户能在项目内快速确定每场的影调、光影、景别和运镜起点。

## 产品决策

采用本地、可解释的三选建议，而不是自动替用户决定风格：

- 每场显示 3 个影调方案和 3 个运镜方案。
- 建议根据原文显式信号排序，例如不安/线索/门窗优先悬疑方案，行走/穿过空间优先观察或跟随方案。
- 卡片显示具体的色彩、光线、构图和运动描述，不使用导演姓名作为模型提示词。
- 点击方案仅填充当前为空的本场视觉字段；已有场次覆盖、项目视觉圣经和镜头卡字段都优先保留。
- 用户可以从已有影调与运镜工作台继续做更细选择；这里是“快速场次起点”，不是替代资料库。

## 数据与交互

`scene-assistant-data.js` 新增本地推荐目录与 `buildSceneCreativeSuggestions(scene, draft)`：

- `looks`: 3 个 `{ id, label, color, lighting, cameraTexture, reason }`。
- `cameras`: 3 个 `{ id, label, framing, movement, reason }`。

`project-scenes.js` 在“剧本分析草稿”下方显示两组卡片：

- 影调建议：点击“采用影调”，只补 `scene.visualOverride` 的色彩、光线、摄影字段。
- 运镜建议：点击“采用运镜”，只补当前镜头的 `framing`、`movement`；默认 `中近景 / 缓慢推进` 被视为可替换的起始值，用户手动填写的值永不覆盖。

## 验收

- 含“不安、照片、门”的场次优先显示“悬疑逼近”。
- 含“穿过、走近、奔跑”的场次优先显示“观察跟随”。
- 选择方案后，右侧本场提示词立刻出现对应影调或镜头描述。
- 已有自定义色彩、光线、摄影、景别或运镜不被改写。
- 自动测试与本地两场剧本验收通过，临时数据清理。
