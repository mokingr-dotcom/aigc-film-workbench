# AIGC 影视生产资产与镜头交付设计

## 目标

把现有“提示词工作台”推进为可从剧本出发、稳定沉淀镜头生产资料的本地预制作台。第一阶段不接入视频生成 API，不重做界面，不改变既有项目数据。

## 用户流程

`导入剧本 → AI 导演拆场拆镜 → 全片资产盘点 → 资产母版确认 → 逐镜选择静帧/15秒/30秒 → 生成单镜交付包 → 保存正式提示词版本 → 记录生成结果 → 导出全片镜头包`

## 范围

### 全片资产账本

资产从所有场次扫描得到，而非只依赖当前场。角色、场景、道具均显示：编号、名称、出现的场次、出现次数、母版状态、参考图数量与待办提示。点击引用场次仍进入相应场次。

### 资产母版状态

资产状态固定为：`draft`、`needs_master`、`has_reference`、`review`、`locked`、`revision`。新资产默认为 `needs_master`；上传至少一张参考图后进入 `has_reference`；只有用户明确锁定才是 `locked`。道具和角色/场景一样可以绑定参考图。

### 镜头时长合同

每个镜头有独立 `deliveryMode`：`still`、`seedance15`、`seedance30`。旧数据按照时长迁移：15 秒及以下为 `seedance15`，其余为 `seedance30`。镜头编辑器选择模式后，生成提示词与交付 Markdown 使用相应结构。30 秒 Seedance 必须输出 `0–10 / 10–20 / 20–30` 三段，15 秒输出 `0–5 / 5–10 / 10–15` 三段。

### 正式提示词版本

镜头可以保存“正式版本”。版本保存提示词快照、时长模式、目标模型、锁定资产编号、创建时间、说明。当前正式版本一眼可见；后续生成结果可追溯到其使用的提示词版本。

## 不在本阶段实现

- 云端账号、多人协作、付费订阅。
- 后端 API 代理和实际调用视频生成模型。
- 自动判定人物、场景或道具视觉质量。
- 对整部 70 分钟长片一次性无人工确认地完成导演级拆解。

## 验收

1. 两场剧本中的同一人物、地点、道具在资产账本里只出现一条，且列出两个场次。
2. 没有参考图的关键资产不显示为“已锁定母版”。
3. 道具可上传和显示参考图。
4. 场 01 镜 03 选择 30 秒后，单镜提示词和导出 Markdown 都包含三段 30 秒节奏。
5. 保存 V1、编辑提示词、保存 V2 后，两个版本均可读，当前版本正确切换。
6. 原有项目、导入导出、生成结果与测试保持可用。
