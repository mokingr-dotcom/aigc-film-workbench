# 角色视觉参考与提示词模板工作台设计

## 目标

将“角色定妆”从容易被理解为内置生图工具的界面，调整为供导演、摄影师和 AIGC 创作者长期使用的角色视觉参考与提示词模板工作台。当前阶段不接入任何生图 API，不提供模型选择、生成队列、结果画布或计费功能。

用户在工作台中完成四件事：选择角色建立方式、选择版式样板、填写角色资料、复制可在外部生图模型中使用的完整中文提示词。

## 核心原则

- 保留现有角色档案、角色字段、参考图本地上传和项目持久化能力。
- 不删除旧项目中的参考图、版本元数据或角色资料。
- 页面文案不暗示网站能够直接生成图片。
- 每种版式都提供一张本地图片样板，图片完整显示，不裁切、不拉伸。
- 两种来源模式和四种版式分别生成与其目标一致的提示词。
- 不接入网络图片、云存储、模型 API、订阅或计费功能。

## 信息架构

### 左侧：角色与模板选择

保留角色档案列表，显示当前角色编号、姓名与身份。角色档案下方提供两组互斥选择：

1. 来源模式
   - 有参考图
   - 文字新建角色
2. 版式模板
   - 单视图
   - 三视图
   - 四视图
   - 身份资料板

将“生成来源”改为“角色建立方式”，将“参考图转视图”改为“有参考图”，避免让用户误以为页面会直接调用模型。

### 中间：16:9图片样板

中间区域是模板样板画布，不是生成结果画布。点击四种版式时，画布切换对应的本地图片样板，并显示简短的构图标签。

- 单视图样板：一名角色的高精度正脸或轻微 45 度近景，突出脸部身份、年龄、皮肤和发型。
- 三视图样板：正脸身份特写、45 度半身、正面全身。
- 四视图样板：正脸身份锚点，以及正面、90 度侧面、背面、45 度全身。
- 身份资料板样板：16:9 组合图片，包含人物主肖像、服装拆解、固定道具、表情组和动作姿态组。

所有样板使用 `object-fit: contain` 完整显示。样板图是构图和信息层级参考，不作为固定人物输出。

有参考图模式保留上传、替换和删除入口。上传图作为提示词中的身份参考资产，在样板画布内以清晰的“当前参考图”区域显示，但不得覆盖或替代版式样板说明。文字新建角色模式不要求上传图片。

### 右侧：角色资料与提示词模板

右侧保留现有角色身份字段，并补充身份资料板需要的内容：

- 服装层级与材质
- 固定道具与佩戴位置
- 常态表情
- 情绪表情组
- 标志性动作
- 常用站姿与身体状态

保留年代、影片类型、影调、皮肤质感、影棚光照、画面比例和参考图保留策略等已有选择。

输出标题由“固定角色生图提示词”改为“角色视觉提示词模板”。主操作为“复制提示词”。页面仍可把角色摘要发送到 15 秒运镜和海报工作台，但不出现“开始生成”或模型相关按钮。

## 两种来源模式

### 有参考图

用户上传一张人物参考图。提示词必须：

- 将参考图设为唯一身份优先级。
- 锁定脸部几何、真实年龄、肤色、发际线、发型和体型。
- 按用户选择的单视图、三视图、四视图或身份资料板补全信息。
- 对参考图未展示的侧面、背面、下装和道具执行保守补全。
- 禁止换脸、平均脸、美化年轻化和跨面板身份漂移。

若参考图无法恢复，只显示错误状态，并禁用复制提示词；不删除旧项目元数据。

### 文字新建角色

用户不上传人物图片。提示词必须先根据文字建立唯一身份，再将同一身份复用于目标版式。脸部身份锚点、年龄、体型、发型和服装为核心必填信息。该模式不显示缺少参考图的校验错误。

## 四种提示词模板

### 单视图

适合首次探索人物形象。输出一张近景身份候选图，只出现一个人物和一张脸，优先保证面部、年龄、皮肤、发型和角色气质。提示词明确不生成侧面、背面或拼接多视图。

### 三视图

适合确认脸部与全身比例。提示词固定三块信息：正脸大头特写、45 度半身、正面全身，并锁定三个面板的身份、服装和光照一致性。

### 四视图

适合建立稳定角色母版。提示词包含正脸身份锚点，以及正面、侧面、背面和 45 度全身，强调相同身高、脚底基线、摄影机高度和服装结构。

### 身份资料板

适合项目长期复用和跨工作台传递。采用 16:9 组合版：

- 人物主肖像约占 40%。
- 服装拆解约占 20%。
- 道具、表情和动作共约占 40%。

提示词按以下固定章节输出：人物身份、身体比例、服装层级、固定道具、常态表情、情绪表情组、动作姿态组、统一光照与材质、身份一致性、限定负面。

身份资料板不得变成海报、故事场景、分镜表或 UI 信息图。图片中不生成文字、编号、水印或 Logo；信息分区依靠构图完成。

## 版本区调整

主界面不再强调“身份候选版本”和“保存版本”。该区域改为“模板样板说明”，展示当前版式的用途、构图组成和适用阶段。

旧项目中已有的版本数据继续保留在项目状态中，不自动删除。此次改版不提供版本编辑或迁移操作，避免破坏现有资产。

## 状态与数据

工作台状态新增：

- `layout: "identity"`，表示身份资料板。
- 服装、道具、表情和动作补充字段。

现有 `source`、`layout`、`referenceAsset`、角色字段和年代类型选择继续兼容。导入旧项目时，缺少新增字段应使用空字符串；旧版单视图、三视图和四视图选择保持不变。

## 本地视觉资产

制作四张与当前浅色专业工作台一致的本地样板图。人物样板保持真人写实、白底影棚、低反光真实皮肤和完整构图。身份资料板必须清楚展示五类信息，但不使用文字标签作为图片内容。

样板资产放入现有 `assets/` 目录，通过本地相对路径加载，不依赖外网。

## 验收标准

- 页面明确呈现“角色视觉参考与提示词模板”定位，不出现直接生图的误导。
- 有参考图和文字新建角色两种模式均可正常切换。
- 单视图、三视图、四视图和身份资料板均有独立图片样板与独立提示词。
- 身份资料板提示词完整包含人物、服装、道具、表情和动作。
- 有参考图模式保留上传、替换、删除与刷新恢复。
- 文字新建角色模式无需参考图即可复制完整提示词。
- 旧角色资料和参考图可正常恢复。
- 1440、1280 和 390 宽度下无内容遮挡、不可读文本或图片裁切。
- 所有现有回归测试通过，并增加身份资料板、样板切换、新字段持久化和文案定位测试。

## 非目标

- 不调用图像生成模型。
- 不建设生成结果画布。
- 不提供模型参数、生成队列、额度、计费或 API 密钥设置。
- 不建设完整角色 CRUD 或云端素材库。
- 不重构影调、运镜、海报和画面反推工作台。
