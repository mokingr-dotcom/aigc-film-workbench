# 镜头生成结果回填设计

## 目的

把项目工作台从“复制提示词后就结束”推进到可追溯的 AIGC 镜头生产流程。

创作者在 Seedance、即梦、可灵、Runway 等外部平台生成后，能回到对应镜头登记实际结果，并能在整片项目中明确区分：待生成、关键帧通过、视频已生成、待返工和已锁定。

## 用户结果

在任一选中镜头中，用户可以建立多个生成版本。每个版本包含：

- 关键帧图片，可作为本轮生成的视觉凭据；
- 外部视频结果链接，可直接跳回实际生成平台或云盘；
- 实际使用的平台或模型、模型版本与 Seed；
- 生成参数或补充说明；
- 返工原因或审核备注；
- 是否为该镜头当前选定版本。

用户能够为某一镜选择一个版本作为当前有效结果。镜头状态随之更新，但状态不会代替结果记录。

## 范围

### 包含

1. 为每条镜头新增轻量 `productionResults` 数据：最多保留 12 个版本，仅保存元数据、关键帧参考图 ID 与外部链接。
2. 在当前镜头编辑区增加“镜头生成回填”面板。
3. 用户可上传关键帧图片、填写外部视频链接、平台/模型、模型版本、Seed、备注和返工原因。
4. 用户可选定一个版本为当前镜头结果，或删除一个未选定的错误版本。
5. 面板将版本与既有镜头状态连接：
   - 新建回填默认为“关键帧完成”；
   - 填写结果链接后可标为“视频已生成”；
   - 标记返工原因后可标为“需返工”；
   - 选定通过版本后可标为“已锁定”。
6. 整片交付 Markdown 增加每镜选定版本的实际模型、Seed、外部链接和备注。
7. 项目总览增加已生成、待返工、已锁定的镜头计数。

### 不包含

- 不接入或调用任何外部图像、视频、音频模型 API。
- 不在浏览器中保存大型视频文件，不做本地视频播放器或剪辑器。
- 不承诺自动判断关键帧是否人脸、服装、光线或空间一致；这属于后续“视觉连续性审核”。
- 不改变当前剧本分析、镜头拆分或提示词编排逻辑。
- 不在本期实现跨电脑完整项目 ZIP 迁移；该能力依赖参考图与关键帧的成包导出，作为下一项独立交付。

## 数据设计

在 `normalizeSceneShot` 中加入：

```js
productionResults: [{
  id: "result-...",
  versionLabel: "V1",
  platform: "seedance",
  modelVersion: "Seedance 1.5 Pro",
  seed: "",
  resultUrl: "https://...",
  keyframeReferenceId: "project-ref-...",
  notes: "",
  revisionReason: "",
  selected: false,
  createdAt: "ISO date"
}]
```

规范化规则：

- 单镜最多 12 条，按创建时间保留最近记录；
- `resultUrl` 仅接受 `https:` 链接，空值允许；
- `keyframeReferenceId` 复用现有项目参考图 IndexedDB，不复制 Blob 到项目 JSON；
- 一个镜头最多一条 `selected: true`；后选版本自动取消旧选择；
- 删除版本时同步删除仅被该版本引用、且未被项目资产引用的关键帧图片；
- 旧项目没有 `productionResults` 时自动迁移为空数组。

## 交互设计

位置：当前镜头的“镜头计划”之后、“导演卡”之前。它是当前镜头的生产记录，不创建新工作台。

### 1. 当前状态

面板头部显示：镜头编号、当前状态、回填版本数、当前选定版本。没有版本时明确显示“尚未回填外部生成结果”。

### 2. 新建回填

用户点击“登记生成结果”后出现一张紧凑表单：

- 关键帧图片上传，可选；
- 外部视频链接，可选；
- 平台或模型，预设 Seedance、即梦、可灵、Runway、Pika、其他；
- 模型版本、Seed；
- 生成备注；
- 返工原因；
- 保存为关键帧完成、视频已生成或需返工。

链接和关键帧至少填一项，避免建立没有任何凭据的空版本。图片只是关键帧，不是角色或场景母版。

### 3. 版本列表

版本以时间倒序排列。每条显示缩略图或占位、版本号、平台/模型、Seed、状态、备注。操作为：

- 设为当前选定版本；
- 打开外部结果；
- 删除该版本。

已选定版本不能直接删除，必须先选定其他版本或取消选定。这样项目不会无意失去当前有效结果。

### 4. 交付与总览

单镜提示词仍只负责复制给模型。整片交付包增加“选定生成结果”一节，但不把未选定的历史版本写入默认 Markdown。

生产条显示：总镜头、生成就绪、已生成、待返工、已锁定。它反映生产进度，不替代镜头的基础生成条件。

## 异常与边界

- 上传失败或 IndexedDB 不可用时，不创建版本并给出明确错误；已有镜头数据不受影响。
- 外部链接必须是安全的 `https:` 地址，不在站内嵌入第三方视频。
- 用户可为没有关键帧的外部视频链接建立版本，也可先上传关键帧但暂不填视频链接。
- 切换镜头后，未保存的新增表单不写入项目数据。
- 旧项目、导入项目和没有参考图的项目都应能继续打开。

## 验收

1. 新建项目与旧项目均可打开镜头生产面板。
2. 单镜可保存多条生成版本，并且最多只存在一个选定版本。
3. 关键帧上传保存到现有项目参考图存储，项目 JSON 只保存 ID。
4. 填写 `https` 结果链接、模型、Seed、备注后，重新打开项目仍能保存。
5. 选定版本后，镜头状态和生产总览正确更新。
6. 删除非选定版本不会误删被其他资产或版本使用的图片。
7. 默认整片 Markdown 仅导出选定版本，不泄露被淘汰的历史版本。
8. 桌面与窄屏下，版本卡和表单不遮挡镜头编辑、提示词或现有资产锁定区。
9. 全量回归测试通过，并在本地浏览器完成一条镜头“上传关键帧 → 登记链接 → 选定版本 → 导出整片镜头包”的端到端验证。
