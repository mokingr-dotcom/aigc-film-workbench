# 项目镜头交付包设计

## 目的

让创作者在完成剧本拆场、镜头编辑和连续性锁定后，把整部项目带成一份可按镜生成的交付包，而不是逐场来回寻找和复制提示词。

## 用户结果

用户在项目制作区看到清晰的交付概览，并可：

- 复制整部片的镜头生成提示词；
- 下载 UTF-8 Markdown 文件；
- 按场次和镜头顺序检查每条镜头是否可生成；
- 在每一条镜头前看到目标模型、时长、制作状态和缺失条件；
- 追溯本场锁定的人物、场景、道具参考母版。

这不是备份功能，也不是直接调用视频模型。它只输出可审阅、可编辑、可送入外部模型的文字交付单。

## 范围

### 包含

1. 新增纯数据模块 `project-delivery.js`，从项目、场次、镜头和已有 `buildSceneShotPrompt` 生成确定性的交付包。
2. 按 `场 01 / 镜 01` 排序；每个镜头独立输出。
3. 输出项目摘要、视觉母版、锁定资产、每场简报、每镜提示词与生成状态。
4. 对未就绪镜头标记“待补条件”，但仍保留其草稿，方便团队继续编辑。
5. 在项目制作概览增加“复制整片镜头包”和“下载 Markdown”两个明确动作。

### 不包含

- 不接 Seedance、即梦、可灵或其他模型 API。
- 不上传项目素材到服务器。
- 不改变现有单镜头复制、整场镜头包、项目备份导出。
- 不做多人协作、版本审批或 PDF 排版。

## 数据与格式

交付包对象：

```js
{
  title,
  filename,
  summary: { sceneCount, shotCount, readyShotCount, pendingShotCount },
  markdown,
  scenes: [{ number, title, status, estimatedDurationSeconds, assets, shots: [...] }]
}
```

`markdown` 固定按项目、场、镜头排版。镜头段必须有：编号、时长、目标模型、制作状态、就绪状态、待补条件、完整中文提示词。资产只列名称与稳定 ID，不包含浏览器 Blob 或本地图片二进制。

## UI

在现有 `SCENE PRODUCTION DESK` 头部动作区增加：

- `复制整片镜头包`
- `下载 Markdown`

旁边展示：`已就绪 X / Y 镜`。没有场次时两个按钮禁用并给出空状态文案。复制成功只在按钮上短暂反馈，不弹遮挡页面的模态框。

## 验收

- 场次和镜头严格按数字升序，不受内存数组原顺序影响。
- 每镜使用已有标准提示词构建器，不能另起一套提示词逻辑。
- 镜头未就绪时包中明确列出缺失条件。
- 锁定资产、场次状态和目标模型进入对应镜头上下文。
- 文件名安全、可下载、没有路径字符。
- 现有全量测试保持通过。
