# 剧本驱动场次制片台

## 产品决定

项目中心不再以“15 秒运镜”或单一提示词为主入口，而是作为一部 AIGC 影片的预制作与生成控制面。

主路径固定为：

`剧本 -> 场次分析 -> 场次计划 -> 镜头计划 -> 单镜头标准视频提示词 -> 生成回填`

其中，一场戏是完整的叙事单元；一个镜头是可被视频模型独立生成的片段。15 秒仅是 Seedance 的默认镜头时长，不是场次时长，也不是影片结构。

## 核心界面

### 场次总览

每一场用一行或一张紧凑制作卡呈现：场号、场名、地点、时间、剧情目标、预计时长、镜头数量、出场角色、生成进度和风险提示。用户能一眼判断一部片子有多少场、总时长、还有多少镜头未生成。

### 单场制片页

选中场次后，顶部是本场简报：叙事目标、人物情绪曲线、关键台词、空间与连续性资产、影调与光影。中部是按顺序排列的镜头计划，每条镜头清楚显示时长、景别构图、动作表演、运镜、声音和状态。

### 单镜头生成卡

一个镜头对应一张可编辑的标准视频生成卡。提示词按稳定顺序输出：叙事与人物、表演与动作、场景与连续性资产、影调与光影、景别构图、运镜与节奏、声音、模型约束与负面限制。用户可以直接修改任意字段并复制当前镜头，或复制整场镜头包。

## 数据与规则

- 场次保存 `estimatedDurationSeconds`，默认等于镜头时长合计，也允许用户调整为叙事预估并显示差异。
- 镜头保存独立时长与制作状态；默认 15 秒，但可为 5、8、10、12、15 秒或自定义。
- 剧本解析只产生场次草稿与可编辑建议，不覆盖用户已编辑的镜头、资产和视觉信息。
- 影调、光影、角色、地点、道具、音乐和运镜作为场次/镜头的参考与继承来源，只有被选择后才写入当前镜头提示词。
- 完整场次不能被一键当作一个视频提交；必须由多个镜头独立生成并在剪辑中串接。

## 第一阶段范围

第一阶段优先让用户清楚地完成“导入剧本后，得到一部片子每场的时长、镜头数、镜头提示词”。不接入外部模型 API，不伪装自动生成结果；保留现有本地剧本解析、手动编辑、复制、项目保存和工作台跳转。

## 验收

1. 场次列表可以明确显示每场时长、镜头数和生成进度。
2. 任意场次至少可包含多个不同时长的镜头。
3. 选中镜头时，只显示并复制该镜头的标准视频提示词。
4. 复制整场时，以镜头顺序导出完整镜头包，并包含时长和剪辑提示。
5. 所有改动可保存在当前项目，刷新页面后仍然存在。
