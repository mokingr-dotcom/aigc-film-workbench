# 制作指挥台设计

## 目标

把现有的提示词资料与项目工作台收束为一个可交付的 AIGC 影视制作流程：用户能从项目页知道当前最影响生成的缺口，并直接进入相应的场次、镜头或资产处理。

## 设计决定

项目页顶部新增“制作队列”，不新建第七个工作台。队列从已有项目数据派生，不写入额外状态，分为四类：剧本、资产母版、镜头提示词、生成结果。每条任务显示原因、数量、优先级和一个明确的跳转动作。

任务判定遵循制作顺序：没有场次时先处理剧本；场次出现但资产未锁定时先处理资产；资产就绪后检查每一镜是否已有正式提示词；提示词锁定后提示登记或检查生成结果。这样不会鼓励在角色和场景未锁定前批量生成视频。

## 交互

- 点击“去剧本”进入剧本步骤。
- 点击“去资产”进入资产步骤。
- 点击“处理场次 / 处理镜头”选择对应场次和镜头，打开场次制作界面。
- 点击“登记结果”打开对应镜头的结果登记面板。
- 当没有阻塞任务时，队列展示“可交付”状态，并保留复制整片镜头包入口。

## 数据与安全

队列是纯派生数据模块 `project-production-queue.js`；只读取 `scenes`、`assetLocks`、镜头正式版本与生成结果。它不会调用模型、上传文件或修改项目。所有行动仍复用现有项目持久化和资产引用规则。

## 验收

1. 空项目首先提示导入或粘贴剧本。
2. 有场次但未锁定角色、场景、道具时，资产任务优先出现。
3. 资产锁定后，没有正式提示词的镜头进入镜头任务。
4. 有正式提示词但没有生成结果的镜头进入结果任务。
5. 所有状态满足时，队列显示可交付。
