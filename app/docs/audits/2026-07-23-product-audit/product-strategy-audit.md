# AIGC 电影视觉工作台：产品审阅与路线图

审阅日期：2026-07-23

## 一句话定位

面向中文影视、广告与短内容创作者的 **AIGC 预制作与镜头执行台**：把剧本、参考、角色、场景和镜头规则组织成可直接交付给不同生成模型的连续镜头包。

不是“提示词大全”，也不和视频生成模型竞争。

## 当前优势

1. 影调、光影、导演、类型、中国影视与场景参考的中文资料密度高，且已经具备可检索、可保存、可插入的结构。
2. 15 秒运镜已经不是单纯的运镜词，而包含参考影片、空间调度、时间节奏、表演与声音，接近真正的镜头设计。
3. 海报模块同时覆盖主视觉提示词、中文英文标题设计、可编辑图层和本地下载，适合电影宣传物与商业内容。
4. 角色、海报、运镜、音乐都以项目为单位保存；这比一次性提示词工具更接近生产过程。
5. 本地优先保存对早期创作者有隐私优势，但未来需要提供清晰的备份和团队协作选项。

## 当前主要问题

### 1. 用户第一眼不知道应该先完成什么

项目首页同时出现视觉圣经、剧本输入、场次台、六个工作台与项目库。功能完整，但首要成果不明确：用户不知道下一步应该得到“一场可生成视频”，还是“一个完整项目”。

### 2. 工作台之间还像并列工具，而不是一条创作链

影调、运镜、角色、海报、音乐都很丰富，但用户需要自己判断何时进入、选了什么、是否回写到当前场次。最关键的“当前场次”尚未成为唯一中心。

### 3. 缺少 AIGC 连续性控制层

电影创作真正昂贵的是重做：角色脸、服装、地点、道具、时间与上一镜衔接发生漂移。当前有参考与提示词，但缺少资产状态、锁定母版、镜头引用和返工原因。

### 4. 三类用户混在同一条路径

短片导演、广告团队与自媒体/商品图用户的第一步不同。全部用“影视项目”进入，会让轻量用户觉得重，让专业用户又觉得不够生产化。

### 5. 参考片与导演标签需要更克制地产品化

参考影片非常有价值，但最终输出应优先使用可执行的摄影、色彩、构图和节奏描述，不应把“模仿某导演”作为卖点或主要生成指令。这样更专业，也能降低风格混杂与商业合规风险。

## 建议的核心体验

```text
建立项目
  -> 导入 / 编写剧本
  -> 自动拆为场次与镜头草稿
  -> 选择一场
  -> 锁定人物、场景、道具、影调
  -> 生成模型适配的镜头提示词
  -> 标记：待生成 / 已生成 / 需返工 / 已锁定
  -> 导出镜头包
```

主界面要只问一个问题：

> 当前这一场，是否已经具备可以稳定生成的条件？

## 建议的产品结构

### 主产品：镜头包生产台

每个场次展示：剧本原文、人物与资产、场景与关键道具、影调、镜头、声音、目标模型、最终提示词、生成状态与版本。

场次卡而不是工具页，成为用户日常停留的页面。

### 资料库：作为插入式能力

影调库、运镜库、角色定妆、音乐库不应要求用户离开场次页面。每个库应以“插入到本场”打开，并明确告诉用户替换的是哪一项。

### 宣传与商业内容：独立轻量入口

“电影 / 剧集 / 广告短片”使用项目镜头包流程；“自媒体封面 / 商品主图 / 短广告”使用更短的商业视觉任务流。它们共用影调、标题字、产品与人物参考，但不共用复杂的剧本入口。

## 优先级路线图

### P0：让用户在十分钟内完成一条镜头（最高优先）

1. 首页改为三个明确入口：`做影视项目`、`做广告短片`、`做商业图片`。
2. 影视项目默认打开“本场镜头包”，而不是空的剧本表单。
3. 给剧本导入提供一个可见的示例项目和三场示例，用户无需先写内容就能理解结果。
4. 每个场次增加“生成就绪度”：人物、场景、动作、影调、镜头、限制六项是否齐全。
5. 将各资料库的插入动作统一成“替换本场色彩 / 光影 / 摄影 / 运镜”，每个维度只保留一个生效项。

### P1：建立真正的连续性壁垒

1. 资产账本：角色、地点、道具都有 ID、参考图、状态与版本。
2. 锁定状态：`母版已锁定`、`本场使用`、`需返工`、`已废弃`。
3. 场次连续性检查：同一角色的脸、发型、服装、道具和伤痕在相邻镜头发生变化时给出提示。
4. 镜头版本与生成记录：保留输入提示词、目标模型、参考资产、结果链接、问题标签。
5. 项目导出：按场次导出 Markdown / CSV / DOCX 镜头包，方便交给制作与剪辑。

### P2：订阅与团队版本

1. 云端项目、备份与跨电脑同步。
2. 团队角色：导演、摄影、制片、设计、客户只看到各自需要的面板。
3. 评论、审批与镜头锁定记录。
4. 项目模板市场：短剧、悬疑短片、品牌片、产品广告、纪录片、动画等。
5. 模型连接器：先做“导出到模型”，再考虑代替模型内部生成。

## 建议的差异化表述

不要说：`全球电影提示词库`。

建议说：

> 从剧本到可生成镜头包的 AIGC 影视预制作台。
> 把人物、场景、影调、调度和声音锁进同一条镜头提示词，减少重做与画面漂移。

## 市场判断

LTX Studio 已覆盖“剧本到故事板”的一体化路径；Runway 已提供多模型工作流、参考媒体复用与生成编辑；Adobe Firefly Boards 已覆盖情绪板、故事板与协作探索。因此，本产品不适合复制一个英文通用画布。

更有机会的切口是：`中文影视语言 + 本土商业内容 + 模型无关的镜头连续性管理`。用户愿意为节省返工次数、保持人物一致、快速交付一组可执行镜头而订阅，而不会仅为几十条额外提示词付费。

参考：

- LTX Studio：script-to-storyboard、镜头与声音调整、视觉参考控制。
- Runway：参考媒体复用、多模型流程、短片拼接与角色一致性。
- Adobe Firefly Boards：情绪板、故事板与协作式创意探索。
- Suno：完整音乐生成与更细粒度的音乐编辑，说明本产品的音乐模块应定位为“影视配乐导演提示词与交付规范”，而不是另一个音乐生成器。

## 衡量是否有价值

上线后重点测量：

1. 新用户从进入到复制第一条镜头提示词的时间。
2. 一个项目中完成镜头包的场次数与平均返工次数。
3. 用户是否在同一场次使用过角色、影调、运镜或声音参考。
4. 用户是否导出镜头包并在七天内回到同一项目继续创作。
5. 专业用户是否愿意保存锁定资产，而不只复制提示词。
