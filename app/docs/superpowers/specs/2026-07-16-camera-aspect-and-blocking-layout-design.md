# 15秒运镜双画幅与空间调度布局设计

日期：2026-07-16

## 目标

修正 15 秒运镜工作台中部监视器视觉比例不明确、时间轴空白过多、空间调度路径过小，以及左右信息栏显示压力过大的问题。保留现有数据、字段 ID、案例选择、提示词生成和复制逻辑。

## 桌面布局

- 左侧大师运镜库宽度调整为 320px，保证案例标题、分类和调度摘要可读。
- 右侧镜头生成器宽度调整为 440px，保证标签、输入内容和完整提示词有稳定阅读宽度。
- 中部为弹性工作区，承担监视器、时间轴和空间调度路径。
- 1025–1280px 宽度使用较紧凑的 290px / 弹性中栏 / 400px。
- 1024px 以下沿用纵向堆叠，不产生横向滚动。

## 监视器画幅

- 提供 `21:9` 与 `16:9` 两个互斥画幅按钮，采用紧凑分段控制。
- 默认选择 `21:9`，突出电影监看感，并为下方调度信息释放垂直空间。
- `21:9` 使用 `aspect-ratio: 21 / 9`，桌面最大高度 300px。
- `16:9` 使用 `aspect-ratio: 16 / 9`，桌面最大高度 360px。
- 图片始终使用 `object-fit: contain`，不得拉伸或裁切。
- 切换状态保存在本地工作台状态中；刷新页面后恢复上次选择。
- 画幅切换只控制监看显示，不改写案例提示词中的成片画幅要求。

## 中部信息层级

- 舞台网格行改为：工具栏、按画幅自适应监视器、内容高度时间轴、可选空间调度路径。
- 时间轴取消填满剩余高度的行为，按实际内容自然收紧。
- 没有空间调度地图时，中部底部允许保留少量背景，不把空白插入时间轴内部。
- 展开空间调度地图时，它紧接在时间轴之后显示。

## 空间调度路径

- 展开区域桌面最小高度 210px，内部三张路径卡完整显示。
- 路径卡维持起点、转折、落点三列，并提高节点标题、时间和说明文字的可读性。
- 中等宽度下仍保持三列；窄屏下改为单列纵向路径。
- 调度地图区域拥有独立边界和背景层级，与时间轴明显区分。

## 交互与可访问性

- 画幅按钮使用真实按钮和 `aria-pressed` 状态。
- 键盘可聚焦、可切换；选中态不只依赖颜色。
- 保留“调度地图”和“保存版本”现有按钮行为。
- 画幅切换不清空当前案例、表单内容或生成提示词。

## 验收标准

- 1440px 桌面下左右栏信息完整，中栏不压迫两侧。
- 两种画幅实测比例分别接近 2.333:1 与 1.778:1。
- 画面无拉伸、无裁切；页面无横向溢出。
- 展开 C07 空间调度地图后，时间轴下方不再出现大片无意义空白。
- 空间调度区域高度不少于 210px，三张路径卡内容完整可读。
- 1280、1024、600 和 390px 宽度布局正常。
- 现有自动测试与浏览器交互测试全部通过，控制台无错误。
