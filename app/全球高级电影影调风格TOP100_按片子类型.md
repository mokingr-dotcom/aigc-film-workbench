# 全球高级电影影调风格 TOP100（按片子类型）

说明：这里的“排名”不是票房榜、奖项榜或影史权威榜，而是按 **高级感、电影质感、AIGC 可用性、类型片适配度、光影辨识度** 综合整理的创作参考排名。  
用法：每条都可以直接复制到提示词里，也可以和“人物/场景/镜头/负面约束”组合使用。

## 快速组合公式

```text
主体 + TOP影调风格 + 光影色调 + 材质空间 + 镜头语言 + 情绪 + 负面约束
```

示例：

```text
海边旧旅馆，一个女人站在走廊尽头回头看，冷峻心理惊悚高级影调，冷蓝灰低饱和，低照度，强侧光，暗部保留细节，潮湿墙面，长走廊透视，浅景深，真实电影摄影，孤独、危险、被监视感，避免卡通感，避免过曝，避免塑料皮肤
```

# 使用建议

1. 做短片或网大前，先从本清单里选 1 个主影调，不要一场戏混太多风格。
2. 如果是恐怖、悬疑、犯罪，优先选 031-050 区间，稳定出高级感。
3. 如果是 AIGC 古装、奇幻、史诗，优先选 011-030、055-060。
4. 如果是都市爱情、青春、文艺，优先选 001-010、061-070。
5. 如果要导入网页生成器，可以把每条的“提示词”作为 `types` 数据，名称用 `高级影调001 - 克制现实主义高级影调` 这种格式。
