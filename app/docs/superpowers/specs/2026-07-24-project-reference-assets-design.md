# 项目参考资产母版设计

## 目标

让 AIGC 创作者把角色三视图、角色定妆图和场景参考图保存为项目资产，并在每场戏中明确引用。镜头提示词必须输出资产名称、编号和一致性规则，避免只靠文字描述维持人物与空间连续性。

## 用户流程

1. 在项目的“资产母版”中新建角色或场景资产，上传一张或多张参考图并填写名称、描述与锁定规则。
2. 角色资产可从角色定妆工作台导入已有身份母版；场景资产可直接上传图片并填写空间、时间、光影说明。
3. 在场次剧本台选择本场出场角色和场景母版。
4. 本场的每个镜头自动继承所选资产，生成提示词时输出“参考资产”和“连续性规则”。
5. 用户可替换资产版本、解除本场引用或锁定场次；不会删除其他场次仍在使用的资产。

## 数据边界

- 图片二进制继续保存在现有浏览器本地资产存储中，不写入项目 JSON。
- 项目 JSON 只保存资产元数据：id、类别、名称、描述、锁定规则、参考图片 id、版本号。
- 场次只保存引用 id，不复制资产内容。
- 角色资产类别固定为 `character`，场景资产类别固定为 `location`；道具沿用现有文字资产锁定，不在本阶段增加图片道具库。

## 界面

- 项目资产账本新增“参考资产母版”区：角色与场景分组、缩略图、版本、引用场次。
- 本场锁定资产区新增“引用角色母版”和“引用场景母版”入口；无图片时明确显示为文字资产，避免误认为已经锁定视觉参考。
- 场次制作简报显示当前引用的角色和场景参考图缩略图；镜头编辑区不重复上传。

## 提示词规则

对每个镜头输出：

- `【角色参考资产】`：角色名称、资产编号、引用图片编号，以及脸部、发型、服装、体型连续性规则。
- `【场景参考资产】`：场景名称、资产编号、引用图片编号，以及空间结构、光线方向、关键物件连续性规则。
- 当没有图片但有文字锁定资产时，只输出文字资产，不声称存在参考图。

## 错误与限制

- 图片仅支持 JPG、PNG、WebP；单张大小和数量沿用项目本地参考图限制。
- 资产上传失败时不创建半成品引用。
- 删除资产前检查全部场次引用；仍被引用时只允许解除当前场引用，不能直接删除资产。
- 本阶段不调用生图或视频模型，不上传用户图片到外部服务。

## 验收

- 上传角色、场景参考图后可在项目刷新后恢复元数据与预览。
- 同一角色被两场引用时，提示词都含同一个资产编号与一致性规则。
- 解除一场引用不会影响另一场。
- 没有参考图的旧项目仍可正常编辑和生成提示词。
