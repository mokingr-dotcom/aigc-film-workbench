# 角色定妆参考图本地持久化设计

## 目标

为角色定妆工作台补齐真实参考图工作流。用户可以上传、拖入、预览、替换和删除角色参考图；图片在刷新页面、关闭浏览器和重新打开项目后仍然保留，并能作为角色列表、身份画布和版本记录的统一视觉来源。

本阶段只处理本地参考图资产，不接入云存储、账号系统、AI 生图接口或多人协作。

## 用户体验

### 空状态

- 新项目不再自动显示固定示例角色图。
- 参考图模式下，16:9 身份画布显示明确的拖拽区域，并提供“选择参考图”和“载入示例”两个操作。
- 文字新建角色模式不强制上传图片，画布显示“角色形象待生成”的中性空状态。

### 上传与预览

- 支持点击选择文件和拖拽上传。
- 接受 JPEG、PNG、WebP，单张原始文件不超过 15MB。
- 上传成功后使用 `object-fit: contain` 在 16:9 画布内完整显示，不裁切人物。
- 画布显示文件名、像素尺寸和文件大小，并提供“替换”和“删除”操作。
- 替换图片时沿用当前角色文字设定；删除图片只删除图片资产，不清空角色表单。
- 上传失败时保留原有图片，并在画布附近显示可读错误信息。

### 工作台联动

- 当前角色列表缩略图、身份画布和后续版本记录引用同一个素材 ID。
- 切换角色或重新打开项目时，根据当前角色记录恢复正确图片。
- “载入示例”会把示例图作为一份本地素材保存，行为与普通上传一致。
- 参考图模式没有图片时，校验区提示“需要上传参考图”；文字新建角色模式不出现该错误。

## 技术方案

### 数据边界

保留现有 `localStorage` 项目 JSON 作为轻量元数据存储，只在角色记录中增加图片引用：

```js
referenceAsset: {
  id: "asset-uuid",
  name: "reference.webp",
  type: "image/webp",
  width: 1600,
  height: 1200,
  size: 842311,
  updatedAt: "2026-07-15T10:00:00.000Z"
}
```

图片二进制写入独立的 IndexedDB 数据库，项目 JSON 不保存 Base64 图片。这样避免 `localStorage` 容量不足，也便于未来把本地素材 ID 替换为云端素材 ID。

### 模块划分

- `casting-asset-store.js`：封装 IndexedDB 的打开、写入、读取和删除，只暴露基于素材 ID 的 Promise API。
- `casting-app.js`：管理上传交互、校验、预览 URL 生命周期、角色元数据和工作台状态。
- `index.html`：提供文件输入、拖拽画布、状态信息以及替换/删除按钮，保留现有工作台 ID 和 `data-workspace` 契约。
- `casting-option-3.css`：只增加上传空状态、拖拽反馈、图片信息和操作按钮的视觉规则，不改变已确认的三栏总体布局。

### 图片处理

- 浏览器先校验 MIME 类型和 15MB 上限，再使用 `createImageBitmap` 或图片元素读取像素尺寸。
- 原图最长边超过 2560px 时，等比缩小到最长边 2560px；较小图片保留原始尺寸。
- JPEG 与 WebP 使用 WebP 质量约 0.9 存储；带透明通道的 PNG 保留 PNG，避免白底边缘异常。
- IndexedDB 保存处理后的 Blob 和完整元数据。界面通过临时 Object URL 显示图片，并在替换、删除、切换角色或页面卸载时释放 URL。

## 数据流

1. 用户选择或拖入图片。
2. 前端完成格式、大小、可解码性和尺寸校验。
3. 图片按规则压缩或保留，并写入 IndexedDB，返回素材元数据。
4. 当前角色保存 `referenceAsset` 引用，随后调用现有项目保存机制。
5. 画布、角色缩略图和版本记录通过素材 ID 读取 Blob 并显示。
6. 替换成功后删除旧 Blob；若新图片处理失败，旧图片保持不变。
7. 删除图片时先更新角色引用，再删除无引用 Blob，避免界面指向不存在的素材。

## 异常与兼容

- IndexedDB 不可用或写入失败：说明“浏览器无法保存该图片”，不把临时预览伪装成已保存状态。
- 文件类型错误、超过 15MB 或图片损坏：拒绝上传并保留当前图片。
- 元数据存在但 Blob 丢失：清理失效引用并恢复上传空状态。
- 旧项目没有 `referenceAsset`：按空状态加载，不迁移固定示例图。
- 项目导出本阶段仍只导出 JSON 元数据，不声称包含图片；导出区域明确标注“本地图片素材未包含”。完整项目打包留到后续云端或 ZIP 资产导出阶段。

## 测试与验收

### 自动测试

- 接受 JPEG、PNG、WebP，拒绝其他格式和超过 15MB 的文件。
- 上传成功后角色元数据包含素材 ID，刷新后可以从 IndexedDB 恢复。
- 替换失败不会删除旧图片；替换成功会释放旧引用。
- 删除图片后角色表单仍保留，参考图校验恢复为未完成。
- 文字新建角色模式在无图时仍可生成提示词。

### 浏览器视觉验收

- 以 2048px、1440px、1280px 和窄屏检查 16:9 画布、完整构图和按钮可读性。
- 实测拖拽、选择、替换、删除、载入示例、刷新页面和关闭后重新打开。
- 确认左侧角色列表、中间画布和版本卡片显示同一张图，没有裁切、拉伸或旧示例残留。
- 完成后启动本地服务，并提供带新缓存参数的可点击地址。

## 非目标

- 不调用图片生成模型。
- 不实现云端上传、跨电脑同步、登录、订阅或权限系统。
- 不在本阶段实现完整角色增删改查。
- 不把本地素材二进制嵌入当前项目 JSON 导出文件。
