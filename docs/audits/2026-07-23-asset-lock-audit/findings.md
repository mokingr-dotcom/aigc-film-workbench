# 场次资产连续性验收

- 已修复：同一场的多个出场人物会分别建立角色母版，不再只锁定角色定妆工作台里的一个人物。
- 已修复：人物、地点、关键物件可通过“一键锁定本场资产”写入项目资产账本，并以稳定编号进入本场视频提示词。
- 已修复：资产面板在填写后即时显示待锁定项；已有锁定资产与新增待锁定项同时可见。

- 已新增：项目资产账本按角色、场景、道具展示每项资产的编号、母版细节与引用场次；点击场次编号可回到对应场次。
- 已修复：删除场次时自动回收未被其他场次引用的资产；旧项目可清理未引用资产。
- 已新增：跨场连续性检查只提示“本场出现已有资产，但遗漏了母版编号引用”的技术缺口，并说明可能造成的人物、空间或道具漂移。
