# Seedance电影大师级运镜提示词库

用途：给 Seedance / AIGC 视频模型使用的电影镜头语言参考库。重点不是模仿某一位导演，而是把世界电影里成熟的类型片镜头方法，整理成可执行的提示词结构。

整理方法：不以平台官方提示词指南为结构依据，而是根据世界电影中的场面调度、演员表演、摄影机运动、构图、光线、色彩和声音逻辑，由AI进行归纳与生产化改写。所有案例只提炼可复用的镜头机制，不复制原片角色、造型或具体画面；统一改写为适合15秒连续真人电影镜头、可上传角色参考图的执行结构。

### 3. 人物表演词库：避免“参考图角色很死”

不要只写“人物害怕”或“人物悲伤”，要把情绪翻译成可见行为。

- 克制恐惧：呼吸变浅，眼神先扫向声源再回避，肩膀轻微抬高，手指收紧，下颌僵住，脚步短暂停顿。
- 怀疑警觉：眉头轻收，视线停在一个细节上，身体不完全转向目标，重心后移，手保持随时可动作的状态。
- 压抑愤怒：鼻翼轻张，咬紧后槽牙，手背筋络绷起，胸口起伏加深，但声音和大动作仍被压住。
- 疲惫麻木：眨眼缓慢，肩颈下沉，动作有半拍延迟，呼吸沉重，视线短暂失焦后重新聚焦。
- 悲伤克制：避免嚎哭；先吞咽、压住呼吸、眼眶变湿，目光不敢停留，嘴角轻微颤动，最后才有一滴泪。
- 决心形成：起初目光游移，随后呼吸放慢，身体重心向前，抬眼锁定目标，手部动作从犹豫变得稳定。

场景描述建议至少写六层：地点时代、空间几何、材质旧化、光源位置、空气天气、可运动环境。不要只写“高级办公室”“阴森老宅”“未来城市”。

### 6. Seedance使用原则

1. 一个15秒提示词只做一个连续镜头，镜头内部可以有表演变化，但不要写成多个机位的剪辑段落。
2. 15秒至少安排四个动作节拍，每个节拍都要有因果关系；避免角色15秒一直走路、一直回头或一直盯着镜头。
3. 主要运镜只选一种，必要时允许一次克制拉焦；写清摄影机从哪里到哪里、移动多远、速度如何变化。
4. 光影必须写可解释的光源和方向，人物走动时光线变化要符合空间逻辑。
5. 角色参考图锁定身份，提示词必须补充这个镜头独有的表演状态；不要用文字重新创造一张与参考图冲突的脸。
6. 场景没有参考图时，文字至少写清空间结构、材质、时代、天气、光源和动态环境。
7. 一条提示词只使用一部参考片的摄影语言，不要同时混合三部电影的影调。
8. 复杂打斗不要在一个15秒镜头内堆叠过多招式，优先保证动作因果、人物一致性和摄影机可执行性。

### 7. 大师级镜头调度固定提示词结构（角色参考图版）

这套结构不依赖某个平台的官方指南，而是从经典电影调度方法反推出来。核心判断是：角色参考图负责“是谁”，提示词负责“人物为什么动、怎么动、摄影机为什么跟、光线如何随动作变化”。镜头调度不是运镜词的堆砌，而是人物、空间、摄影机、光线和声音在15秒内共同完成一个叙事变化。

```text
【01 镜头叙事任务】
这是一个15秒连续长镜头。本镜头只完成一件事：[发现线索 / 权力逆转 / 进入危险 / 关系疏离 / 做出决定 / 逃离失败]。观众在第0秒知道[信息A]，第15秒新增知道[信息B]。

【02 角色参考图与身份锁定】
```

### 8. 判断一个镜头调度是否高级的六条标准

1. 人物移动有动机：角色因为看见、听见、害怕、决定或被迫才移动。
2. 摄影机移动有触发：人物行动或信息变化发生后，摄影机才跟随或揭示。
3. 空间关系可读：观众知道人物从哪里来、要去哪里、危险和出口在哪里。
4. 表演有过程：情绪不是一个形容词，而是从微反应发展到决定和动作。
5. 光线参与叙事：人物走进或离开某种光，不只是画面漂亮，而是关系发生变化。
6. 结尾产生新状态：15秒结束时，人物、信息或权力关系必须和开头不同。

#### 01 《历劫佳人》（1958）开场：悬念物件穿越多人空间

核心调度：先让危险物件进入画面，再让摄影机越过街道、人物和车辆，危险始终存在却不占据中心。观众知道炸弹存在，角色不知道，悬念来自信息差。

AI化拆解：前景危险物，中景主角，背景目标车辆；摄影机升高后横移，再降低靠近人物。群演只做单一方向运动，避免互相穿插。硬质夜灯、招牌光和车灯把街道分成多个光区。



### B. 悬疑、权力与信息揭示

#### 05 《教父》（1972）餐厅段落：缓慢推进表现内心决定

核心调度：人物身体动作极少，真正的变化发生在眼睛、呼吸和沉默里。摄影机在角色做出决定前极慢推进，让背景逐渐退出，观众被迫进入人物心理。

AI化拆解：先保持三人关系可见，再让画外声音触发主角；主角不立刻行动，先停顿、吞咽、抬眼。推进速度要慢，主要动作放在最后三秒。

影调光影：干净明亮，颜色略不自然，对称构图，空间秩序感强。

大师级运镜：固定对称镜头，突然横移，人物严肃地进入荒诞空间。

镜头调度：人物站位像舞台，物件排列整齐，喜剧来自画面秩序和行为反差。

Seedance提示词：

```text
15秒连续电影长镜头，16:9。一个穿制服的人严肃地推着小餐车穿过粉色酒店走廊。荒诞喜剧影调，明亮均匀光，粉色、芥末黄和薄荷绿配色，空间严格对称。固定广角中景，人物从画面左侧进入，沿中心线走向远处。镜头保持静止，画面像舞台，动作认真但情境滑稽。主体清晰，构图稳定，无跳切。
```

### 18 音乐歌舞

参考片：雨中曲（1952）、芝加哥（2002）、爱乐之城（2016）

影调光影：舞台追光、蓝紫与金色、镜面反射、烟雾、高饱和局部色。

大师级运镜：环绕舞者，升降揭示舞台，横移配合群舞队形。

镜头调度：人物动作和镜头运动同节奏，灯光变化配合情绪高潮。

Seedance提示词：

```text
15秒连续电影长镜头，16:9。夜晚空旷街道上，一位舞者在路灯下旋转。音乐歌舞片影调，蓝紫夜色与金色路灯对比，地面有轻微反光，空气中有薄雾。中景，镜头围绕舞者缓慢半环绕，保持舞者在画面中心。裙摆和灯光形成圆形运动，节奏浪漫、轻盈、电影化。动作连贯，人物清晰，无文字水印。
```

### 19 历史宫廷

参考片：巴里·林登（1975）、宠儿（2018）、末代皇帝（1987）

影调光影：烛光、金色低照度、丝绒、油画质感，深红、暗棕、宫殿空间。

大师级运镜：缓慢推轨，静态油画构图，人物在华丽空间中被权力压住。

镜头调度：人物走位受礼仪限制，蜡烛、帷幕、柱廊制造层次。

Seedance提示词：

```text
15秒连续电影长镜头，16:9。宫廷宴会后，一位贵族独自穿过烛光长廊。历史宫廷片影调，金色烛光，深红丝绒，暗棕木质和油画质感，暗部保留细节。中远景，柱廊和帷幕形成纵深。镜头沿走廊缓慢后退，人物向镜头走来，动作克制而庄重。情绪华丽、孤独、权力压迫。主体清晰，无跳切。
```

### 20 纪录片现实主义

参考片：人生七年（1964）、寻找小糖人（2012）、亲爱的，不要跨过那条江（2014）

影调光影：自然光、真实环境噪点、手持观察、低饱和，不摆拍。

大师级运镜：轻微手持跟随，固定观察，人物自然进入和离开画面。

镜头调度：空间不完美但真实，声音和环境细节增强现场感。

Seedance提示词：

```text
15秒连续电影长镜头，16:9。清晨市场里，一位老人整理摊位上的蔬菜。纪录片现实主义影调，自然晨光，低饱和，真实环境纹理，背景人群自然流动。中景手持观察，镜头轻微跟随老人手部动作，不做夸张运动。前景偶尔有人经过遮挡，保持真实现场感。动作自然，主体清晰，无文字水印。
```

### 21 动画电影

参考片：千与千寻（2001）、寻梦环游记（2017）、海洋之歌（2014）

影调光影：色彩明确，角色轮廓清晰，背景层次丰富，光影服务情绪和空间深度。

大师级运镜：横向视差移动，升降揭示奇观，跟随角色穿过场景。

镜头调度：角色、前景、背景分层，动作清楚，奇观逐步揭示。

Seedance提示词：

```text
15秒连续动画电影长镜头，16:9。一个小女孩提着灯笼走过夜晚的神秘街道。动画电影影调，暖黄色灯笼光、蓝紫夜色和丰富背景层次，角色轮廓清晰，手绘或高质量动画质感。中景，前景有灯笼和招牌形成视差。镜头横向缓慢跟随角色移动，背景建筑逐层展开。情绪神秘、温柔、奇幻。角色保持一致，动作连贯，无文字水印。
```

### 22 中国国风神话

参考片：大闹天宫（1961）、哪吒之魔童降世（2019）、白蛇：缘起（2019）

影调光影：青绿、朱红、金色、墨黑，云雾、庙宇、山海神兽，东方奇观。

大师级运镜：升降揭示神话空间，环绕法器或角色，云雾中推进。

镜头调度：人物在云海、山门、庙宇、法阵之间移动，衣袂和光效带节奏。

Seedance提示词：

```text
15秒连续电影感动画长镜头，16:9。一个少年站在云海中的古老山门前，手中法器发出微光。中国国风神话影调，青绿山水、朱红符纹、金色轮廓光和墨黑暗部，云雾流动。宽幅中远景，山门巨大，人物居中偏下。镜头从云雾中缓慢推进并轻微升高，揭示山门和远处神兽剪影。节奏庄严、东方奇幻、史诗感。主体清晰，动作连贯。
```

## 四、常用大师级运镜动作词

### 稳定高级类

- 缓慢推进：适合悬疑、心理、爱情、宫廷、黑色电影。
- 缓慢后退：适合孤独、告别、角色进入未知空间。
- 横移跟拍：适合都市、动作、爱情、青春、动画。
- 固定长镜头：适合现实主义、家庭伦理、荒诞喜剧。
- 升降揭示：适合史诗、奇幻、科幻、国风神话。

### 紧张临场类

- 手持跟拍：适合战争、追逐、纪录片、犯罪。
- 低机位跟拍：适合赛博朋克、动作、黑帮。
- 主观视角推进：适合恐怖、悬疑、噩梦。
- 前景遮挡穿行：适合秘密跟踪、街道、市场、战场。

### 情绪诗意类

- 半环绕：适合爱情、歌舞、梦境、角色觉醒。
- 从暗处走入光里：适合人物转变、揭示真相。
- 从光里退回暗处：适合背叛、危险、失落。
- 视线转向线索：适合推理、悬疑、刑侦。
- 远景中人物变小：适合史诗、孤独、命运感。

## 六、Seedance避坑清单

1. 不要一条提示词写完整剧情，先写一个可执行镜头。
2. 不要混用多个电影参考片，最多只选一部作为影调参考。
3. 不要写“高级、震撼、大片感”后就结束，要写具体光源、构图、运镜。
4. 不要让主体同时做太多动作，比如奔跑、回头、拔枪、跳跃、落地、说话。
5. 不要同时要求“手持晃动”和“画面绝对稳定”，会互相冲突。
6. 不要在 5 秒镜头里写复杂剪辑，Seedance 更适合单镜头连续运动。
7. 不要只写“镜头很电影”，要写景别、焦段感、镜头方向和速度。
