# 海报自由文字图层设计

## 目标

把现有“标题合成”升级为轻量海报排字工具：用户上传或生成海报底图后，可以编辑中英文片名、添加宣传语/演员/日期/演职员表/自定义文字，并下载完成海报。

## 核心交互

- 海报底图固定为不可编辑背景。
- 中文片名与英文副标作为默认文字图层保留。
- “添加文字”可建立宣传语、演员、日期、演职员表或自定义文字图层。
- 选择图层后，通过常驻多行文本框编辑内容；空格与回车原样保留。
- 每层独立设置字体方向、颜色、宽度、字距、行距、对齐、旋转、透明度和快速位置。
- “锁定位置”只禁止拖动与缩放，不禁止选择、改字、换行或更换样式。
- 自定义文字图层可复制、删除、显示/隐藏；默认中英文标题不可删除。
- 所有图层随项目保存，并参与撤销、重做和原尺寸 PNG/JPG 导出。

## 边界

- 当前版本使用系统可用中文/英文字体方向，不承诺每台设备具有相同商业字体。
- AI 生成的艺术字标继续作为透明 PNG 图层处理，可移动缩放但不可逐字编辑。
- 描边、阴影、局部变形、用户字体文件导入留到后续增强。
