# 海报上传、字标合成与高清导出设计规格

## 1. 目标

把现有海报监视器从静态示意区升级为可完成真实业务交付的本地海报标题合成工作台。用户可以上传自己生成的海报底图，使用可编辑的中英文标题或上传外部 AI 生成的透明字标 PNG，在监视器中完成排版并按原图分辨率下载最终海报。

本阶段不接入生图 API，不把任何用户图片上传到网络。

## 2. 与字标资料库的关系

海报工作台分成两个相互衔接、职责独立的能力：

1. **48套 AI 片名字标资料库**：帮助用户选择设计方向并生成适合外部 AI 模型的字标提示词。
2. **本地海报合成器**：负责上传海报、编辑文字、上传透明字标、排版和高清下载。

用户可以只使用可编辑文字，也可以把资料库提示词复制到外部模型生成透明字标 PNG，再回到本地合成器上传并排版。

## 3. 技术方向

使用 Fabric.js 7.4.0 作为图层选择、拖动、缩放、旋转、文字编辑和画布导出的核心引擎。依赖文件固定保存在项目本地，不使用 CDN；Fabric.js 使用 MIT 许可证。

新增清楚的职责边界：

- `poster-asset-store.js`：只负责 IndexedDB 图片 Blob 的保存、读取、删除、配额和格式校验。
- `poster-compositor.js`：只负责画布、图层、变换、吸附、预览和导出。
- `poster-app.js`：继续负责海报工作台表单、字标资料库、项目状态和两个模块之间的编排。
- `vendor/fabric.min.js`：固定版本的本地画布依赖，不从网络加载。

不把画布算法继续堆入已经较大的 `poster-app.js`。

## 4. 用户工作流

### 4.1 初始状态

- 没有用户底图时继续显示现有本地示例海报。
- 监视器明确显示“示例画面”，并提供“上传海报”主入口。
- 示例海报不能导出为用户作品，点击下载时提示先上传自己的海报。

### 4.2 上传海报

1. 用户点击“上传海报”。
2. 选择 JPG、PNG 或 WebP。
3. 系统校验文件类型、文件大小、像素尺寸和解码结果。
4. 上传成功后，监视器画布自动切换为海报原始宽高比。
5. 底图锁定在最底层，不可误选、拖动或缩放。
6. 当前中英文标题和已上传透明字标继续叠加显示。

### 4.3 标题来源

提供两个可以同时存在的标题来源：

- **可编辑文字**：中文片名和英文副标题各自为独立图层。
- **透明字标 PNG**：用户从外部 AI 或设计软件获得的字标资产。

中文、英文和 PNG 字标各自可以显示、隐藏、锁定、选择和恢复默认位置。

### 4.4 编辑操作

- 单击图层：选中并显示边框与控制点。
- 拖动：独立移动中文、英文或 PNG 字标。
- 双击中文或英文：直接进入文字编辑，输入过程实时同步右侧输入框；点击画布空白或按 Escape 结束编辑，Enter 保留为多行片名换行。
- 角部控制点：等比例缩放。
- 旋转控制点：旋转，按住 Shift 时以 15 度吸附。
- 右侧参数：字号、字距、行距、对齐、旋转、透明度、显示、锁定和恢复默认。
- 删除键只允许删除 PNG 字标；中文和英文图层只能隐藏，避免误删项目片名。
- 撤销与重做第一版只覆盖当前会话最近 30 次图层变换，不写入项目历史版本。

### 4.5 对齐辅助

- 显示画面中心线、水平中心线和 5% 安全区。
- 图层中心距离辅助线不超过画布短边 1% 时自动吸附。
- 吸附发生时短暂高亮对应辅助线。
- 提供顶部、中央、底部、左下、右下五个快速位置命令。
- 关闭“辅助线”只隐藏视觉线，不关闭安全区坐标和导出边界。

### 4.6 下载

- 默认导出 PNG，保留完整画布和最高质量。
- 可切换高质量 JPG，质量固定为 0.92。
- 导出尺寸默认为上传海报的原始像素尺寸。
- 文件名：`POSTER_项目名_片名_宽x高_v001.png` 或 `.jpg`。
- 下载前显示尺寸、格式和估计文件大小。
- 只导出海报底图和可见图层，不导出选择框、控制点、安全区和辅助线。

## 5. 画布与分辨率模型

- Fabric 画布逻辑坐标使用上传海报的原始像素尺寸。
- 监视器只通过 CSS 尺寸和画布缩放显示，不改变逻辑像素。
- 所有图层项目状态保存为归一化值：
  - `x`、`y`：图层中心相对于画布宽高的 0 至 1 比例。
  - `widthRatio`：图层宽度相对于画布宽度的比例。
  - `rotation`：-180 至 180 度。
  - `opacity`：0 至 1。
- 可编辑文字额外保存 `fontSizeRatio`、`letterSpacing`、`lineHeight`、`align` 和系统字体族 ID。
- 切换不同底图时保留归一化位置，但按新画布宽度重新计算图层像素尺寸。
- 底图上传后不提供裁切，第一版始终导出完整原图构图。

## 6. 文件与安全限制

### 6.1 海报底图

- 类型：`image/jpeg`、`image/png`、`image/webp`。
- 单文件上限：20 MB。
- 最大边长：12,000 像素。
- 最大总像素：50,000,000。
- 文件扩展名不能替代实际 MIME 与解码校验。

### 6.2 透明字标

- 类型：仅 `image/png`。
- 单文件上限：20 MB。
- 最大边长：8,000 像素。
- 最大总像素：32,000,000。
- 没有透明像素时允许使用，但显示“该 PNG 没有检测到透明区域”的非阻断提示。

### 6.3 禁止项

- 不接收 SVG、PDF、PSD、AI、GIF、视频或远程 URL。
- 不执行文件名、EXIF、PNG 文本块中的内容。
- 不把 Blob 转成大段 Base64 写入 localStorage。
- 所有预览 URL 使用 `URL.createObjectURL`，替换、删除、项目切换和页面卸载时及时 `revokeObjectURL`。
- 图片解码失败时保留当前有效画布，不先删除旧资产。

## 7. 本地资产与项目状态

### 7.1 IndexedDB 资产

每个海报项目最多保存：

- 一张海报底图。
- 一张透明字标 PNG。

Blob 使用稳定资产 ID 存入 IndexedDB；项目 JSON 只保存：

- 资产 ID。
- 原文件名。
- MIME。
- 字节数。
- 宽高。
- 创建时间。
- 透明度检测结果。

### 7.2 更新事务

替换图片使用“候选资产”流程：

1. 校验并保存新 Blob。
2. 更新内存预览和候选元数据。
3. 持久化项目状态。
4. 项目保存成功后删除旧 Blob 并释放旧 URL。
5. 保存失败时恢复旧状态并删除候选 Blob。

删除图片同样先持久化状态，再清理 Blob，避免页面刷新后出现损坏引用。

### 7.3 恢复与缺失

- 重新打开项目时异步恢复底图和字标 Blob。
- 元数据存在但 Blob 缺失时保留元数据并显示“本机图片已丢失”，禁止导出。
- 项目切换期间使用加载令牌，旧项目异步恢复结果不能覆盖新项目。
- 删除项目时收集该项目当前底图和字标资产，只删除没有被其他项目引用的 Blob。

## 8. 图层状态

项目状态新增：

```js
posterCompositor: {
  sourceAsset: null,
  titleAsset: null,
  selectedLayer: "title-cn",
  guidesVisible: true,
  snapEnabled: true,
  exportFormat: "png",
  layers: {
    "title-cn": {
      visible: true,
      locked: false,
      x: 0.5,
      y: 0.78,
      widthRatio: 0.56,
      fontSizeRatio: 0.075,
      letterSpacing: 0,
      lineHeight: 1.05,
      align: "center",
      rotation: 0,
      opacity: 1,
      fontFamily: "cn-serif"
    },
    "title-en": {
      visible: true,
      locked: false,
      x: 0.5,
      y: 0.84,
      widthRatio: 0.38,
      fontSizeRatio: 0.022,
      letterSpacing: 160,
      lineHeight: 1,
      align: "center",
      rotation: 0,
      opacity: 0.9,
      fontFamily: "en-sans"
    },
    "title-image": {
      visible: true,
      locked: false,
      x: 0.5,
      y: 0.8,
      widthRatio: 0.58,
      rotation: 0,
      opacity: 1
    }
  }
}
```

所有导入状态必须逐字段归一化并限制数值范围。未知图层、字体族和格式回退到安全默认值。

## 9. 字体与字标表现

### 9.1 可编辑文字

第一版只使用本机系统字体栈和明确可用的通用字体族：

- 中文现代黑体。
- 中文电影宋体。
- 中文可读楷体。
- 英文编辑衬线。
- 英文现代无衬线。
- 英文高窄无衬线。

如果某个字体不可用，画布与导出必须使用同一回退字体，保证预览和下载一致。

### 9.2 AI 设计字标

48套字标模板继续负责生成提示词和近似预览。真正具有复杂造字、纹理和光影的字标，应由用户在外部 AI 模型生成透明 PNG 后上传。网站不把普通系统字体伪装成已经生成的 AI 字标。

## 10. 界面布局

### 10.1 左栏

- 保持构图模板、基础标题和 AI 片名字标资料库。
- 48套库、搜索与收藏按独立规格实现。
- 不在左栏增加资产管理，避免模板与文件操作混杂。

### 10.2 中栏

监视器区域成为主要制作区：

- 顶部：底图状态、上传/替换海报、适应窗口、100%查看、辅助线开关。
- 中部：Fabric 画布，尽量利用现有空白区域；画布按原始比例完整显示。
- 底部：当前选中图层、坐标、尺寸、旋转和原图输出尺寸。
- 无底图时显示现有示例和清楚的上传入口，不使用空白大卡片。

### 10.3 右栏

在现有标题参数附近增加“标题合成”组：

- 中文图层、英文图层、PNG字标三个图层行。
- 每行显示选择、显示、锁定和恢复。
- 上传/替换/删除透明字标。
- 当前图层的字号或宽度、字距、行距、对齐、旋转、透明度。
- 快速位置与撤销/重做。
- 导出格式、尺寸摘要和下载按钮。

使用图标按钮表达显示、锁定、恢复、撤销、重做和下载，并提供工具提示。

## 11. 状态与提示词同步

- 双击编辑中文或英文时，同步 `#poster-title` 与 `#poster-english-title`。
- 右侧文字输入变化时同步 Fabric 文字对象。
- 标题位置自动写入提示词：
  - 横向中心百分比。
  - 纵向中心百分比。
  - 宽度占画面比例。
  - 对齐、旋转和与安全区关系。
- 上传透明字标后，合成提示词增加“使用上传透明字标作为最高优先级，保持字形、材质、颜色和透明边缘不变”。
- 独立字标资产提示词不写入海报坐标；只有海报合成描述和完整海报提示词包含坐标。

## 12. 错误处理

- 文件类型或尺寸不合法：不改变当前画布，显示具体原因。
- 浏览器存储配额不足：删除候选资产，恢复旧状态，提示用户清理旧项目图片。
- 图片解码失败：拒绝文件并保留旧资产。
- Fabric 初始化失败：退回只读监视器，保留提示词与项目数据。
- 导出内存不足：先尝试 PNG/JPG 正常导出；失败后提示用户降低原图尺寸，不静默输出低清图。
- 下载过程中按钮显示进度并防止重复导出。
- 页面关闭前不弹出阻断对话框；每次图层变换结束后自动保存项目状态。

## 13. 响应式与可访问性

- 1440 与 1280：保留三栏，监视器获得最大可用空间。
- 1024 与 820：顺序为监视器、资料库、标题合成参数。
- 390：监视器全宽；图层控制单列；下载按钮保持可见；复杂拖动仍可用触摸操作。
- 画布可通过 Tab 聚焦，方向键每次移动当前图层 1 像素，Shift + 方向键移动 10 像素。
- 所有上传入口具有可见标签；图层按钮具有准确的 `aria-pressed` 或 `aria-label`。
- 选择边框不仅依赖颜色，还使用清楚的控制点和图层名称。
- 尊重 `prefers-reduced-motion`。

## 14. 测试与验收

### 14.1 资产测试

- 接受合法 JPG、PNG、WebP 底图。
- 字标只接受 PNG。
- 拒绝伪造 MIME、SVG、超出 20 MB、超出边长或总像素的文件。
- 候选保存失败时旧资产和预览不丢失。
- 替换、删除、切换和项目删除时 Blob 与 Object URL 不泄漏。

### 14.2 图层测试

- 中文、英文和 PNG 字标可以独立选择、拖动、缩放、旋转、隐藏和锁定。
- 双击文字编辑与右侧输入双向同步。
- 图层变换归一化保存并刷新恢复。
- 吸附、安全区和快速位置正确。
- 撤销/重做最多保留 30 步。

### 14.3 导出测试

- PNG 与 JPG 导出像素尺寸等于原图。
- 导出不包含控制点、辅助线和选择框。
- 隐藏图层不进入导出。
- 中文、英文和 PNG 字标的位置与监视器一致。
- 下载文件名安全，不包含非法路径字符。

### 14.4 浏览器与视觉

- 检查 1440×1024、1280×900、1024×900、820×1180 和 390×844。
- 检查鼠标、触摸、键盘编辑。
- 检查长中文片名、长英文片名、竖版与横版海报。
- 检查高分辨率图片内存错误恢复。
- 页面无横向溢出、控制台无错误、底图和标题不被界面遮挡。
- 保存设计稿与真实页面截图并记录到 `design-qa.md`。

## 15. 非目标

- 不接入即梦、豆包、GPT Image、Midjourney 或其他生图 API。
- 不提供照片修图、滤镜、抠图、蒙版、画笔、PSD 或矢量编辑。
- 不提供多张底图、多张透明字标或任意数量图层。
- 不在线同步图片，不建立素材云盘。
- 不打包商业字体。
- 不改变其他工作台。
